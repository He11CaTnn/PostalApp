УСТАНОВЩИК PostalApp (PostalApp_Setup.iss)
==========================================

Инструмент: Inno Setup (Pascal-совместимый скрипт)
Выходной файл: Setup\PostalApp\PostalApp_Setup_v{версия}.exe

Секция [Setup] — общие параметры
----------------------------------
AppName         = PostalApp
AppVersion      = 0.1.22       ← обновляется при каждом релизе
AppPublisher    = User_Company
AppId           = {D9FBD3F3-9362-4900-B109-E998A4F0EA6C}

AppId — уникальный GUID, идентифицирует приложение для Windows.
Не меняется никогда после первой публикации. При изменении Windows
перестаёт распознавать существующую установку и деинсталлятор не найдёт приложение.

DefaultDirName  = {autopf32}\PostalApp
  {autopf32} — папка Program Files (x86) на 64-битных системах и
  Program Files на 32-битных. Обеспечивает правильный путь установки
  независимо от разрядности системы.

DefaultGroupName = PostalApp — название группы в меню Пуск.
DisableProgramGroupPage = yes — страница выбора группы в меню Пуск скрыта.
DisableDirPage = no — страница выбора папки установки отображается.

Compression     = lzma2 + SolidCompression = yes — максимальное сжатие.
PrivilegesRequired = admin — установка требует прав администратора.
ArchitecturesInstallIn64BitMode = x64 — на 64-битных системах приложение
  устанавливается в 64-битном режиме.

OutputBaseFilename = PostalApp_Setup_v0.1.22 — имя файла установщика
  (без расширения). Расширение .exe добавляется автоматически.
OutputDir = Setup\PostalApp — папка вывода относительно .iss файла.

Секция [Files] — включаемые файлы
----------------------------------
Строка 1 — основной exe:
  Source: ...\bin\Release\PostalApp.exe → DestDir: {app}
  Flags: ignoreversion — не проверять версию при перезаписи.
  Перечислен отдельно, чтобы гарантировать его наличие (даже если маска * его пропустит).

Строка 2 — все остальные файлы:
  Source: ...\bin\Release\* → DestDir: {app}
  Excludes: "logs\*,*.pdb,*.xml,*.log"
    logs\*   — вся папка логов не включается в установщик.
    *.pdb    — отладочные символы.
    *.xml    — XML-файлы (документация .NET и манифесты — не нужны пользователю).
    *.log    — лог-файлы.
  Flags: ignoreversion recursesubdirs — рекурсивный обход подпапок.

Эти же исключения синхронизированы с manifests.py (EXCLUDED_DIRS, EXCLUDED_EXTS).

Секция [Tasks] — опциональные действия при установке
------------------------------------------------------
desktopicon    — «Создать ярлык на рабочем столе» (по умолчанию выбрано).
startmenuicon  — «Создать ярлык в меню Пуск» (по умолчанию НЕ выбрано, Flags: unchecked).

Секция [Icons] — ярлыки
------------------------
{autodesktop}\PostalApp → {app}\PostalApp.exe — создаётся только при Tasks: desktopicon.
{userprograms}\PostalApp\PostalApp → {app}\PostalApp.exe — при Tasks: startmenuicon.
Comment — подсказка при наведении на ярлык.

Секция [Run] — запуск после установки
---------------------------------------
{app}\PostalApp.exe
Flags:
  nowait       — не ждёт завершения запущенного приложения.
  postinstall  — показывает чекбокс «Запустить PostalApp» на последней странице.
  skipifsilent — не запускает при тихой (/silent) установке.

Секция [Dirs] — создание папок
--------------------------------
{app}\logs с правами Permissions: users-modify.
Это позволяет Logger записывать файлы в папку logs без прав администратора
даже если приложение установлено в Program Files (защищённая зона).

Секция [UninstallDelete] — очистка при удалении
-------------------------------------------------
Type: filesandordirs; Name: {app}
Удаляет всё содержимое папки приложения при деинсталляции, включая:
  - logs\ (логи)
  - файлы, созданные во время работы приложения
Без этой секции стандартный деинсталлятор удалил бы только те файлы,
которые были установлены, и не тронул бы созданные после установки.

Секция [Languages]
-------------------
Russian.isl — русский язык интерфейса установщика.

Секция [Code] — Pascal-код
----------------------------
InitializeSetup(): зарезервирован (возвращает True, установка разрешена).
CurStepChanged(ssPostInstall): зарезервирован для кода после установки.
CurUninstallStepChanged(usUninstall): зарезервирован для кода при удалении.

Что менять при выпуске новой версии
-------------------------------------
1. AppVersion = {новая версия}
2. OutputBaseFilename = PostalApp_Setup_v{новая версия}
3. Source-пути — если изменилась структура проекта.
Остальное не трогать.
