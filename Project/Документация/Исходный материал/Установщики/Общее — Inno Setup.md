ОБЩИЕ ЗАМЕЧАНИЯ ПО УСТАНОВЩИКАМ INNO SETUP
============================================

Инструмент
----------
Inno Setup — бесплатный компилятор установщиков для Windows.
Скрипт компилируется в один self-extracting EXE через Inno Setup Compiler (ISCC.exe).

Компиляция
----------
Через GUI: открыть .iss в Inno Setup Compiler → Build → Compile (Ctrl+F9).
Через командную строку:
  "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" PostalApp_Setup.iss

Выходной файл появляется в OutputDir (относительно расположения .iss).

Флаг ignoreversion
-------------------
Применён ко всем файлам. Без него Inno Setup при обновлении пропускал бы
перезапись файлов если версия в заголовке PE-ресурсов «не новее».
С ignoreversion файлы всегда перезаписываются — это нужно потому что
у .NET DLL-зависимостей версии могут не отражать реальные изменения кода.

Флаг recursesubdirs
--------------------
Позволяет одной строкой включить все подпапки bin\Release\.
Без него нужно было бы перечислять каждую подпапку отдельно.

Константы {app}, {autopf32}, {autodesktop}, {userprograms}
-----------------------------------------------------------
{app}          — папка куда установлено приложение (DefaultDirName).
{autopf32}     — Program Files (x86) на x64-системах, Program Files на x86.
{autodesktop}  — рабочий стол текущего пользователя.
{userprograms} — меню Пуск текущего пользователя.

PrivilegesRequired = admin
--------------------------
Оба установщика требуют прав администратора.
Причина: запись в Program Files защищена. Без этого флага UAC-диалог
не появился бы и установка упала бы с ошибкой доступа.

Структура кода [Code]
----------------------
Все три процедуры (InitializeSetup, CurStepChanged, CurUninstallStepChanged)
присутствуют в обоих скриптах. В PostalApp они зарезервированы пустыми.
В PostalApp-Extra InitializeSetup содержит реальную логику проверки Python.
