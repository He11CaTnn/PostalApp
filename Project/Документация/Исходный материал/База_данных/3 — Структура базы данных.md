СТРУКТУРА БАЗЫ ДАННЫХ (pochta_db)
==================================

База данных: pochta_db
Пользователь: pochta_admin
Расширение: uuid-ossp (генерация UUID v4)
Всего таблиц: 11 (включая служебную «тест»)

Все первичные ключи — тип UUID, значение генерируется автоматически
функцией uuid_generate_v4() при каждой новой вставке.

──────────────────────────────────────────────────────────────────
ТАБЛИЦЫ АУТЕНТИФИКАЦИИ И ПЕРСОНАЛА
──────────────────────────────────────────────────────────────────

Логин
------
Хранит учётные данные для входа в систему.
  id      UUID, PK, auto
  Почта   varchar(255), уникальный (UNIQUE) — идентификатор при входе
  Пароль  text — PBKDF2-SHA256 хэш в Base64 (соль 16 байт || хэш 32 байта)

Ограничения: Логин_Почта_key (UNIQUE на «Почта»).
Индекс: нет отдельного — покрывается UNIQUE-ограничением.

Сотрудники
-----------
Профиль сотрудника, привязанный к учётной записи.
  id             UUID, PK, auto
  ФИО            varchar(255)
  Роль           varchar(100) — одно из: «Почтальон», «Оператор»,
                               «Руководитель подписок», «Директор»
  Id логина      UUID, FK → Логин.id ON DELETE CASCADE
  Дата создания  timestamp with time zone, default: now()

Индекс: idx_sotrudniki_id_logina (по «Id логина»).
Каскад: удаление Логина → удаление Сотрудника.

Устройства
-----------
Реестр устройств с которых производился вход. Используется для автовхода.
  id                   UUID, auto (без NOT NULL — может быть NULL при сбое генерации)
  Id сотрудника        varchar — Guid сотрудника в строковом виде
  ip                   varchar — внешний IP устройства
  Название устройства  varchar — hostname компьютера
  Местоположение       varchar — город, страна из ip-api.com
  Постоянный доступ    boolean — true = автовход по ID материнской платы разрешён
  Последний вход       timestamp without time zone (UTC, без часового пояса)
  Id материнской платы varchar — SerialNumber из Win32_BaseBoard

Примечание: таблица не имеет внешнего ключа к Сотрудники, т.к.
«Id сотрудника» хранится как varchar, а не uuid. Это сделано для
обратной совместимости на момент проектирования.

──────────────────────────────────────────────────────────────────
ТАБЛИЦЫ КАРТОГРАФИИ
──────────────────────────────────────────────────────────────────

Участки
--------
Почтовые участки — именованные зоны обслуживания.
  id            UUID, PK, auto
  Название      varchar(255)
  Цвет          varchar(50), default: '#3388ff' — hex-код для отображения на карте
  Id сотрудника UUID — почтальон, ответственный за участок

Примечание: внешний ключ к Сотрудники не объявлен — связь логическая,
не физическая. Это даёт гибкость: участок можно создать до назначения сотрудника.

Метки
------
Адресные точки на карте (дома, квартиры, организации).
  id           UUID, PK, auto
  Широта       double precision
  Долгота      double precision
  Тип здания   varchar(100), default: '' — «Частный дом», «Многоквартирный дом» и т.д.
  Улица        varchar(255), default: ''
  Дом          varchar(50), default: ''
  Корпус       varchar(50), default: ''
  Квартира     varchar(50), default: ''
  Id участка   UUID, FK → Участки.id ON DELETE CASCADE
  Id читателей text, default: '' — Guid читателей через запятую (денормализованный список)

Индекс: idx_metki_id_uchastka (по «Id участка»).
Каскад: удаление Участка → удаление всех его Меток.

Узлы
-----
Вершины полигональных границ участков.
  id          UUID, PK, auto
  Широта      double precision
  Долгота     double precision
  Id участка  UUID, FK → Участки.id ON DELETE CASCADE
  Номер       integer, default: 0 — порядковый номер вершины (задаёт обход полигона)

Индекс: idx_uzly_id_uchastka (по «Id участка»).
Каскад: удаление Участка → удаление всех его Узлов.

──────────────────────────────────────────────────────────────────
ТАБЛИЦЫ ПОДПИСОК
──────────────────────────────────────────────────────────────────

Издания
--------
Каталог почтовых изданий (газеты, журналы).
  id                                    UUID, PK, auto
  Индекс                                varchar(50), уникальный — каталожный код издания
  Название                              varchar(255)
  Тип издания                           varchar(100), default: ''
  Минимальный срок подписки             real (месяцы)
  Минимальная цена подписки на дом      real (рубли)
  Минимальная цена подписки на почт     real — «почтовый ящик», усечено до 50 символов в DDL
  Максимальный срок подписки            real
  Максимальная цена подписки на дом     real
  Максимальная цена подписки на поч     real — аналогично

Ограничения: Издания_Индекс_key (UNIQUE на «Индекс»).

Подписки
---------
Оформленные подписки читателей.
  id               UUID, PK, auto
  Срок подписки    varchar(100), default: '' — текстовое значение («6 месяцев» и т.п.)
  Цена подписки    varchar(100), default: '' — текстовое значение
  Комплекты        integer, default: 0 — количество экземпляров
  Дата оформления  timestamp with time zone, default: now()
  Id издания       varchar(50), default: '' — каталожный индекс издания (не UUID)

Примечание: «Id издания» хранит каталожный индекс («Индекс» из Издания),
а не UUID. Это денормализованный дизайн — JOIN-а по id не предусмотрено.

Читатели
---------
Физические лица — получатели почтовых изданий.
  id                    UUID, PK, auto
  ФИО                   varchar(255)
  Id активных подписок  text, default: '' — Guid подписок через запятую

──────────────────────────────────────────────────────────────────
ТАБЛИЦА ЗАДАНИЙ
──────────────────────────────────────────────────────────────────

Задания
--------
Поручения для сотрудников с привязкой к адресным точкам.
  id                  UUID, PK, auto
  Id сотрудника       UUID, FK → Сотрудники.id ON DELETE CASCADE
  Текст               text, default: ''
  Статус              varchar(100), default: 'Назначено'
                      Допустимые значения (задаются приложением):
                        «Новое», «Принято», «В процессе», «Выполнено»
  Дата выдачи         timestamp with time zone, default: now()
  Дата завершения     timestamp with time zone, default: now()
  Прикрепленные метки text, default: '' — Guid меток через запятую

Индекс: idx_zadaniya_id_sotr (по «Id сотрудника»).
Каскад: удаление Сотрудника → удаление всех его Заданий.

──────────────────────────────────────────────────────────────────
СЛУЖЕБНАЯ ТАБЛИЦА
──────────────────────────────────────────────────────────────────

тест
-----
Используется исключительно для проверки живости соединения.
  число  text[]

Приложение при подключении выполняет SELECT к этой таблице — если запрос
прошёл, соединение считается установленным. Содержимое таблицы не важно.

──────────────────────────────────────────────────────────────────
ДИАГРАММА СВЯЗЕЙ
──────────────────────────────────────────────────────────────────

  Логин ──── Сотрудники ──── Задания
                  │
              Участки ──── Метки
                  │
               Узлы

  Издания ──── Подписки ──── Читатели ──── Метки
               (через «Id издания» = Индекс)   (через «Id читателей» и «Id активных подписок»)

Стрелки без физического FK (только логические связи):
  Сотрудники ← Участки.Id сотрудника
  Подписки ← Читатели.Id активных подписок
  Читатели ← Метки.Id читателей
