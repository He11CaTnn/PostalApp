ШАГ 3 — ВАРИАНТ В: ДОМЕН + HTTPS + ВИДИМОСТЬ В ПОИСКЕ
======================================================

Строится поверх Варианта Б. Nginx и сертификат не меняются.
Нужно только убрать запрет индексации и зарегистрировать сайт.

ВНИМАНИЕ: После индексации поисковиком убрать сайт из выдачи сложно.
Убедись что готов к публичности прежде чем выполнять этот шаг.

В.1 — Убрать запрет индексации
--------------------------------
Шаг 1 — Удалить мета-тег из HTML-файлов:
  Через WinSCP открой {ПАПКА_САЙТА}/index.html.
  Найди и удали строку:
    <meta name="robots" content="noindex, nofollow">
  Сохрани. То же самое в {ПАПКА_САЙТА}/admin.html.

Шаг 2 — Изменить robots.txt:
  nano {ПАПКА_САЙТА}/robots.txt

  Заменить содержимое на:
    User-agent: *
    Allow: /

  Сохранить: Ctrl+O, Enter, Ctrl+X.
  (Или просто удалить файл — поисковики по умолчанию разрешат индексацию.)

Перезапуск Nginx не нужен.

В.2 — Зарегистрировать в Google Search Console
------------------------------------------------
1. Открыть: https://search.google.com/search-console
2. Нажать «Добавить ресурс» → «URL-префикс» → ввести https://postalapp.ru
3. Подтвердить права на домен — рекомендуется через TXT-запись в DNS:
   - Google покажет строку: google-site-verification=XXXXX
   - В панели DNS создай TXT-запись:
       Тип: TXT, Имя: @, Значение: google-site-verification=XXXXX
   - Подождать обновления DNS (15–60 минут), нажать «Подтвердить».
   Альтернатива: загрузить HTML-файл верификации в {ПАПКА_САЙТА}/ через WinSCP.
4. После подтверждения нажать «Запросить индексацию» для главной страницы.

В.3 — Зарегистрировать в Яндекс Вебмастер
--------------------------------------------
1. Открыть: https://webmaster.yandex.ru
2. Добавить сайт → ввести https://postalapp.ru
3. Подтвердить аналогично Google (TXT-запись или HTML-файл).
4. После подтверждения Яндекс начнёт индексацию в течение нескольких дней.

В.4 — Что влияет на позицию в поиске
--------------------------------------
Уникальность названия:
  Если название уникальное («PostalApp») — сайт займёт первую строку по этому
  запросу почти сразу, конкурентов нет.

Релевантность контента:
  Слова из поискового запроса должны присутствовать в заголовках h1, h2 и тексте.

HTTPS и скорость:
  Уже настроены — это плюс к ранжированию.

Возраст домена:
  Новые домены первые 3–6 месяцев в «песочнице» — высоких позиций
  по конкурентным запросам не будет. Проходит само.

Ссылочная масса:
  Чем больше других сайтов ссылается — тем выше авторитет.
  Для нового домена = 0, нарабатывается со временем.

Поведенческие факторы:
  Если пользователи быстро закрывают страницу — поисковик понижает позицию.
  Долгое чтение и переходы — повышают.
