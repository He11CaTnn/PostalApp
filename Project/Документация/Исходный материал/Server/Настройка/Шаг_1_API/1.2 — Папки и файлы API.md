ШАГ 1.2 — СТРУКТУРА ПАПОК И ФАЙЛЫ API
=======================================

Все рабочие папки находятся внутри /var/www/
В дальнейшей инструкции {ПАПКА_API}, {ПАПКА_ОБНОВЛЕНИЙ} и {ПАПКА_САЙТА}
обозначают пути которые ты выбираешь сам — запомни их, они понадобятся
во всех следующих шагах.

Создание структуры папок
-------------------------
Создай папку для API-сервера и запомни её путь как {ПАПКА_API}:
  mkdir -p /var/www/postalapp_api
  (пример: {ПАПКА_API} = /var/www/postalapp_api)

Создай папку для файлов обновлений PostalApp и запомни как {ПАПКА_ОБНОВЛЕНИЙ}:
  mkdir -p /var/www/postalapp_updates
  mkdir -p /var/www/postalapp_updates/versions
  (пример: {ПАПКА_ОБНОВЛЕНИЙ} = /var/www/postalapp_updates)

Создай папку для файлов сайта и запомни как {ПАПКА_САЙТА}:
  mkdir -p /var/www/postalapp-site
  (пример: {ПАПКА_САЙТА} = /var/www/postalapp-site)

Права на папки:
  chmod -R 755 /var/www/postalapp_api
  chmod -R 755 /var/www/postalapp_updates
  chmod -R 755 /var/www/postalapp-site

Создание Python venv для API
------------------------------
  cd {ПАПКА_API}
  python3 -m venv venv

Активация venv и установка зависимостей:
  {ПАПКА_API}/venv/bin/pip install fastapi uvicorn asyncpg pydantic

Проверить что всё установилось:
  {ПАПКА_API}/venv/bin/pip list

Должны присутствовать: fastapi, uvicorn, asyncpg, pydantic.

Размещение серверных файлов через WinSCP
-----------------------------------------
Открой WinSCP, подключись к серверу.
Перейди в папку {ПАПКА_API}.
Скопируй туда два файла:

  main.py     — FastAPI-приложение
  config.json — конфигурация баз данных

Структура config.json (пример):
  {
    "databases": {
      "Название отделения": {
        "conn": "ip|port|database|user|password",
        "lat": 55.534449,
        "lng": 58.246835
      }
    }
  }

Поле conn: строка формата "хост|порт|база|пользователь|пароль"
Поля lat/lng: координаты почтового отделения для начального позиционирования карты.
Добавляй столько записей в "databases" сколько почтовых отделений обслуживает система.
При входе сервер перебирает все БД по порядку до первого совпадения логина.

Проверить путь к main.py в сервисе:
  В файле main.py первая строка с открытием файла:
    with open("{ПАПКА_API}/config.json", "r") as f:
  Убедись что путь в этой строке совпадает с {ПАПКА_API}.
  Если отличается — исправь через WinSCP: открой main.py, измени строку, сохрани.

Также проверь путь UPDATES_DIR в main.py:
  UPDATES_DIR = Path("{ПАПКА_ОБНОВЛЕНИЙ}")
  Если путь отличается от выбранного — исправь его.

Проверить что файлы скопированы:
  ls -la {ПАПКА_API}
  Должны быть видны: main.py, config.json, venv/
