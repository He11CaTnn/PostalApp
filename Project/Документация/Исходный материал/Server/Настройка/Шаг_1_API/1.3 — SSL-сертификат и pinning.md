ШАГ 1.3 — САМОПОДПИСНОЙ SSL-СЕРТИФИКАТ И SSL PINNING
======================================================

Зачем нужен самоподписной сертификат
--------------------------------------
API-сервер принимает запросы по HTTPS. Certbot не выдаёт сертификаты
для голых IP-адресов — только для доменных имён. Поэтому для API
создаётся самоподписной сертификат (self-signed). Клиент (PostalApp и
PostalApp-Extra) не проверяет его через цепочку CA — вместо этого
реализован SSL Pinning: в код вшит SHA-256 хэш конкретного сертификата.

Создать папку для сертификата
------------------------------
Запомни путь к папке сертификата как {ПАПКА_CERT}:
  mkdir -p /etc/ssl/pochta
  (пример: {ПАПКА_CERT} = /etc/ssl/pochta)

Сгенерировать сертификат и ключ
---------------------------------
Замени {IP_СЕРВЕРА} на реальный IP-адрес сервера в обеих командах:

  openssl req -x509 -nodes -days 3650 -newkey rsa:2048 \
    -keyout {ПАПКА_CERT}/server.key \
    -out    {ПАПКА_CERT}/server.crt \
    -subj   "/CN={IP_СЕРВЕРА}" \
    -addext "subjectAltName=IP:{IP_СЕРВЕРА}"

Параметры:
  -days 3650   — срок действия 10 лет (не требует обновления)
  -nodes       — ключ без пароля (нужно для автозапуска Nginx)
  -newkey rsa:2048 — RSA 2048 бит

Установить права на ключ:
  chmod 600 {ПАПКА_CERT}/server.key
  chmod 644 {ПАПКА_CERT}/server.crt

Получить SHA-256 fingerprint (нужен для SSL Pinning в коде)
-------------------------------------------------------------
Выполни команду:
  openssl x509 -in {ПАПКА_CERT}/server.crt -outform DER | openssl dgst -sha256 | awk '{print toupper($2)}'

Команда выведет строку вида:
  BC14A0466B54BFB96C9F2B116C519104B9B357374A50DF08FB537C496016008D

Это и есть fingerprint который нужно вставить в C#-код приложений.

Обновить SSL Pinning в коде PostalApp
---------------------------------------
Открой проект PostalApp в Visual Studio.
Найди файл SecureConfig.cs.
Найди константу ExpectedCertFingerprint:
  private const string ExpectedCertFingerprint = "СТАРОЕ_ЗНАЧЕНИЕ";
Замени значение на полученный fingerprint:
  private const string ExpectedCertFingerprint = "BC14A0466...";

Сохрани файл, пересобери Release-сборку.

Обновить SSL Pinning в коде PostalApp-Extra
---------------------------------------------
Открой проект PostalApp-Extra в Visual Studio.
Найди файл LoginForm.cs.
Найди константу ExpectedCertFingerprint и замени аналогично.

ВАЖНО: После смены сертификата (например пересоздал на новом сервере)
нужно обновить fingerprint в ОБОИХ проектах, пересобрать и выпустить
новые версии установщиков. Старые клиенты с прошитым fingerprint
перестанут подключаться к новому сертификату.

Проверить сертификат
---------------------
  openssl x509 -in {ПАПКА_CERT}/server.crt -noout -text | grep -E "Subject:|Not After|IP Address"

Должно показать: CN={IP_СЕРВЕРА}, IP Address:{IP_СЕРВЕРА}, дату истечения.
