ШАГ 1.1 — ПОДГОТОВКА ОПЕРАЦИОННОЙ СИСТЕМЫ
==========================================

Поддерживаемые ОС: Debian 12 / Ubuntu 24.04
Инструменты доступа: PuTTY (терминал), WinSCP (файловый менеджер)

Подключение к серверу через PuTTY
-----------------------------------
Host Name: IP-адрес сервера
Port: 22
Connection type: SSH
Нажать Open → ввести логин и пароль (обычно root или созданный при установке пользователь).

Первые команды после входа
---------------------------
Обновить список пакетов и установить обновления:

  apt update && apt upgrade -y

Установить необходимые базовые инструменты:

  apt install -y curl wget git nano unzip openssl

Проверить, что время на сервере корректное (важно для SSL-сертификатов):

  date

Если часовой пояс неверный — установить нужный (пример для Москвы):

  timedatectl set-timezone Europe/Moscow

Установить Nginx
-----------------
  apt install -y nginx

Проверить что Nginx запустился:

  systemctl status nginx

Должно быть: Active: active (running)

Разрешить Nginx в автозагрузку:

  systemctl enable nginx

Установить Python 3 и pip
---------------------------
Debian 12:
  apt install -y python3 python3-pip python3-venv

Ubuntu 24.04:
  apt install -y python3 python3-pip python3-venv

Проверить версию Python (нужна 3.10+):

  python3 --version

Открыть порты в файрволе
--------------------------
Если на сервере активен UFW (Ubuntu) или nftables/iptables (Debian):

UFW (Ubuntu):
  ufw allow 22
  ufw allow 80
  ufw allow 443
  ufw allow 8080
  ufw enable

Debian 12 (UFW может не быть установлен):
  apt install -y ufw
  ufw allow 22
  ufw allow 80
  ufw allow 443
  ufw allow 8080
  ufw enable

Проверить открытые порты:
  ufw status

Примечание: порт 8080 нужен только для Варианта А сайта (HTTP без домена).
При переходе на Вариант Б/В его можно закрыть.
