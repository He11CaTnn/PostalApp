УПРАВЛЕНИЕ УЗЛАМИ ГРАНИЦ
=========================

Методы: FindNearestNode(), UpdateNodeInDatabase(), DeleteNodeFromDatabase()
Класс: CreateBalancedRegions

Назначение
----------
Узлы (Nodes) — вершины полигональных границ участков, хранящиеся в таблице Узлы.
Операции над узлами производятся непосредственно в БД Access и отражаются на карте.

Поиск ближайшего узла (FindNearestNode)
----------------------------------------
Принимает экранные координаты mouseX, mouseY и опциональный радиус maxDistance (по умолчанию 10 px).

Перебирает balancedRegions (список Region из последней операции).
Для каждой вершины PolygonPoints:
  gMapControl1.FromLatLngToLocal(polygonPoint) → экранные координаты.
  Евклидово расстояние до (mouseX, mouseY).
  Если distance < minDist → обновляется минимум.

Возвращает nullable-tuple (regionId: string, nodePoint: PointLatLng, nodeIndex: int)
или null если ни один узел не попал в радиус.

regionId = region.DbId (Guid из БД Access).
nodePoint = координаты вершины для последующего поиска в БД.

Обновление узла (UpdateNodeInDatabase)
---------------------------------------
Принимает: regionId, oldPoint (старые координаты), newPoint (новые).

UPDATE Узлы
SET [Долгота] = ?, [Широта] = ?
WHERE [Id участка] = ?
  AND ABS([Долгота] - ?) < 0.000001
  AND ABS([Широта] - ?) < 0.000001

Координаты округляются до 6 знаков через Math.Round(value, 6).
Поиск по старым координатам с допуском 0.000001 — идентификация конкретного узла
без использования id (т.к. id узла при перемещении не передаётся).

Удаление узла (DeleteNodeFromDatabase)
---------------------------------------
1. Удаление узла по координатам:
   DELETE FROM Узлы WHERE [Id участка] = ? AND ABS(Долгота - ?) < 0.000001 AND ABS(Широта - ?) < 0.000001

2. Пересчёт номеров оставшихся узлов:
   SELECT id, Долгота, Широта FROM Узлы WHERE Id участка = ? ORDER BY Номер
   Для каждой записи: UPDATE Узлы SET Номер = ? WHERE id = ?
   Номера перенумеруются начиная с 1 без пропусков.
   Это важно для корректного порядка вершин полигона при следующей загрузке.

Важность balancedRegions для редактирования
--------------------------------------------
FindNearestNode() работает только с balancedRegions — списком регионов в памяти.
Если balancedRegions == null (например, после запуска без балансировки) —
узлы не обнаруживаются. Для активации редактирования узлов необходимо сначала
загрузить участки из БД через панель переноса (Access → Карта → Участки или Все данные),
либо выполнить балансировку — оба действия заполняют balancedRegions.

После каждой операции с узлом (добавление, перемещение, удаление):
  LoadRegionsFromNewTables() → balancedRegions = regions → DisplayRegionsOnMap(regions).
Это обеспечивает актуальность balancedRegions для следующего клика.
