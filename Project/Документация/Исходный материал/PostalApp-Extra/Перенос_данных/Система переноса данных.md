СИСТЕМА ПЕРЕНОСА ДАННЫХ
========================

Класс: CreateBalancedRegions
Метод: DataTransferButton_Click

Назначение
----------
Панель переноса данных позволяет перемещать метки, участки и узлы между
тремя источниками: файл addresses.txt, БД Access (BD.accdb) и PostgreSQL-сервер.

Управление
----------
comboBox2 — источник (Файл / Access / Сервер)
comboBox3 — назначение (Карта / Access / Сервер)
comboBox4 — что переносить (зависит от выбора источника/назначения)
DataTransferButton — кнопка «Перенести»

ComboBoxTextUpdate() синхронизирует допустимые варианты comboBox4
в зависимости от комбинации источник+назначение:
  Файл → Карта       : только «Метки»
  Access → Карта     : «Все данные», «Метки», «Участки»
  Access → Сервер    : только «Все данные»
  Сервер → Карта     : только «Все данные»
  Сервер → Access    : только «Все данные»
  Прочие комбинации  : «Недоступно», кнопка заблокирована

Маршруты переноса
-----------------

Файл → Карта → Метки:
  LoadMarkersFromAddresses()
  Читает Data\addresses.txt, парсит CSV, создаёт серые маркеры на карте.
  Старые overlays очищаются перед загрузкой.
  Подробнее: SearchAddresses.py и скрипт поиска адресов.

Access → Карта → Метки:
  EnsureAccessDatabaseStructure() + LoadMarkersFromDatabaseToMap()
  SELECT id, Долгота, Широта, Тип здания, Улица, Дом, Корпус, Квартира, Id участка FROM Метки
  Цвет маркера определяется через IsPointInPolygon() по загруженным полигонам участков.

Access → Карта → Участки:
  LoadRegionsFromNewTables() + DisplayRegionsOnMap() + LoadMarkersFromDatabase()
  Загружает участки с узлами и метки, привязанные к участкам (WHERE Id участка IS NOT NULL).

Access → Карта → Все данные:
  LoadRegionsFromNewTables() + DisplayRegionsOnMap() + LoadMarkersFromDatabaseToMap()
  Загружаются и участки, и все метки (включая без участка).

Access → Сервер → Все данные:
  EnsureAccessDatabaseStructure() + TransferRegionsToServer() + TransferMarkersToServer()
  Подробнее: файл «Перенос Access → PostgreSQL».

Сервер → Карта → Все данные:
  LoadFromServerAndDisplayOnMap()
  Подробнее: файл «Перенос сервер → карта».

Сервер → Access → Все данные:
  EnsureAccessDatabaseStructure() + LoadFromServerToAcccess()
  Подробнее: файл «Перенос сервер → Access».

Пересборка Id участка (button8)
--------------------------------
RebuildMarkersRegionIds():
  Загружает все полигоны участков.
  SELECT id, Широта, Долгота FROM Метки — все метки.
  Для каждой метки: IsPointInPolygon() по полигону каждого участка.
  UPDATE Метки SET [Id участка] = ? WHERE id = ?
  Если точка не принадлежит ни одному участку — Id участка = DBNull.
  Записывается пакетами по 100 записей в транзакции.

UpdateMarkersColors():
  После пересборки перекрашивает маркеры на карте через цвета участков.
  Каждый существующий маркер заменяется новым с цветом определённого участка.
  gMapControl1.Refresh().
