АВТОВОССТАНОВЛЕНИЕ СТРУКТУРЫ БД ACCESS
=======================================

Метод: EnsureAccessDatabaseStructure()
Вспомогательные: TryRepairAccessStructure(), CreateFreshAccessDatabase()
Класс: CreateBalancedRegions

Назначение
----------
Перед каждой операцией, требующей БД (резервное копирование, открытие в Access,
загрузка данных, перенос), вызывается EnsureAccessDatabaseStructure().
Метод гарантирует, что файл BD.accdb существует и содержит корректную структуру таблиц.

Эталонная схема
---------------
Определяется словарём schema внутри EnsureAccessDatabaseStructure():
  Ключ — имя таблицы (Участки, Узлы, Метки).
  Значение — список пар (Column, Ddl): имя столбца и DDL-тип (TEXT(N), DOUBLE, INTEGER).
Схема включает все столбцы описанные в разделе «Структура БД Access».

Шаг 1 — отсутствие файла
--------------------------
Если BD.accdb не существует:
  Directory.CreateDirectory(путь к Data).
  CreateFreshAccessDatabase(dbPath, schema) — создаётся новый пустой файл.

Шаг 2 — файл существует
-------------------------
Открывается OleDbConnection.
Вызывается TryRepairAccessStructure(conn, schema).
Если возвращает false (починить нельзя):
  conn.Close(), File.Delete(dbPath), CreateFreshAccessDatabase().

Если OleDbConnection.Open() бросает исключение (файл повреждён):
  File.Delete(dbPath), CreateFreshAccessDatabase().

TryRepairAccessStructure(conn, schema) → bool
----------------------------------------------
1. conn.GetSchema("Tables") — получает список таблиц.
   Учитываются только TABLE_TYPE == "TABLE".

2. Для каждой таблицы в schema:
   a) Если таблица отсутствует:
      CREATE TABLE [name] (col1 ddl1, col2 ddl2, ...) через DDL.
   b) Если таблица есть:
      conn.GetSchema("Columns", {null,null,tableName,null}) — список столбцов.
      Для каждого отсутствующего столбца:
        ALTER TABLE [name] ADD COLUMN [col] ddl
        Из DDL перед выполнением удаляются: "NOT NULL PRIMARY KEY", "PRIMARY KEY", "NOT NULL"
        (Access не поддерживает эти ограничения в ALTER TABLE ADD COLUMN).

3. Возвращает true при успехе, false при любом исключении.

CreateFreshAccessDatabase(dbPath, schema)
------------------------------------------
1. Type.GetTypeFromProgID("ADOX.Catalog") — создаёт COM-объект ADOX.Catalog.
   Требует установленного Microsoft Access Database Engine (ACE).
   catalog.Create(connectionString) — создаёт пустой .accdb файл.
   Соединение ADOX закрывается, COM-объект освобождается через Marshal.ReleaseComObject.

2. Открывается OleDbConnection к созданному файлу.
   Для каждой таблицы в schema:
     Из DDL каждого столбца удаляются "NOT NULL PRIMARY KEY", "PRIMARY KEY", "NOT NULL".
     Выполняется CREATE TABLE [name] (col1 ddl1, ...)

Резервное копирование (button23)
---------------------------------
EnsureAccessDatabaseStructure() → SaveFileDialog (фильтр *.accdb) →
File.Copy(sourcePath, выбранный путь, overwrite: true).
Имя файла по умолчанию: BD_Backup_{yyyyMMdd_HHmmss}.accdb.
