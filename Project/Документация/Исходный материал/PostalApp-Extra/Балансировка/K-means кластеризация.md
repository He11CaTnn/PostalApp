K-MEANS КЛАСТЕРИЗАЦИЯ
======================

Метод: PerformKMeansClustering(points, clusterCount)
Класс: CreateBalancedRegions

Назначение
----------
Первичное распределение адресных точек по участкам на основе географической близости.
Результат используется как стартовая точка для последующей балансировки по времени.

Инициализация центроидов
------------------------
Для каждого из clusterCount участков случайным образом выбирается одна точка из points
как начальный центроид. При пустом списке точек центроид задаётся случайным смещением
от postOfficeLocation (±0.05° по широте и долготе).
Каждому участку назначается цвет из массива regionColors по модулю длины массива.

Итерационный алгоритм
---------------------
Максимум 100 итераций, цикл прерывается досрочно при отсутствии изменений.

На каждой итерации:
  1. Очищаются списки Points для всех регионов.
  2. Каждая точка назначается региону с ближайшим центроидом.
     Расстояние — геодезическое (формула Haversine в CalculateDistance).
  3. Пересчитываются центроиды:
     avgLat = среднее всех Latitude точек региона,
     avgLng = среднее всех Longitude.
     Если новый центроид отличается от предыдущего более чем на 0.0001° — changed = true.

Завершение: при changed = false или после 100 итераций.
Итоговые центроиды записываются в Region.CenterPoint.

Модели данных
-------------
AddressPoint:
  Id                  — порядковый номер (0..N-1)
  Address             — строка адреса (улица, д., корп., кв.)
  Latitude            — широта
  Longitude           — долгота
  BuildingType        — тип здания
  RegionId            — текущий назначенный регион (индекс)
  DistanceToPostOffice — расстояние до почты в метрах (заполняется в CalculateRegionTimes)

Region:
  Id            — порядковый индекс (0..N-1)
  DbId          — Guid из БД Access (заполняется при LoadRegionsFromNewTables)
  Points        — список AddressPoint
  Color         — Color из массива regionColors
  TotalTime     — суммарное время обхода участка (секунды)
  CenterPoint   — PointLatLng центроида
  PolygonPoints — вершины полигона (= ConvexHullPoints после BuildRegionPolygons)
  ConvexHullPoints — точки выпуклой оболочки

CalculateDistance(lat1, lon1, lat2, lon2) → double (метры)
-----------------------------------------------------------
Формула Haversine:
  R = 6371000 м
  a = sin²(Δlat/2) + cos(lat1)·cos(lat2)·sin²(Δlng/2)
  c = 2·atan2(√a, √(1-a))
  d = R·c

Используется во всём алгоритме: кластеризация, балансировка, расчёт времени.
