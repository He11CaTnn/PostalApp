БАЛАНСИРОВКА УЧАСТКОВ ПО ВРЕМЕНИ
=================================

Методы: CalculateRegionTimes, BalanceRegions, FindBorderPointsBetweenRegions
Класс: CreateBalancedRegions

Параметры времени
-----------------
METER_PER_SECOND = 0.25 — секунд на метр пути (скорость ходьбы ≈ 4 км/ч).
TIME_PER_HOUSE   = 30   — секунд на посещение одного дома.
Оба параметра настраиваемы через диалог UpdateNumberOfRegions() (button4).
numberOfRegions  = 7 — количество участков, также настраивается через тот же диалог.

Расчёт времени участка (CalculateRegionTimes)
---------------------------------------------
Для каждой точки:
  DistanceToPostOffice = CalculateDistance(postOfficeLocation, point)

TotalTime = houseTime + travelTime:
  houseTime   = Points.Count × TIME_PER_HOUSE
  avgDistance = среднее DistanceToPostOffice всех точек участка
  travelTime  = avgDistance × METER_PER_SECOND × 2  (туда и обратно)

Балансировка (BalanceRegions)
------------------------------
Цель: уменьшить разброс TotalTime между участками ниже 10% от среднего.
Максимум 100 итераций.

На каждой итерации:
  1. Определяется максимальный (maxTimeRegion) и минимальный (minTimeRegion) по TotalTime.
  2. Если (max - min) / targetTime < 0.1 — балансировка завершена.
  3. FindBorderPointsBetweenRegions(maxTimeRegion, minTimeRegion):
     Из точек maxTimeRegion отбираются те, для которых расстояние до центра minTimeRegion
     меньше расстояния до собственного центра maxTimeRegion.
     Список сортируется по возрастанию расстояния до центра minTimeRegion.
  4. Первая точка из borderPoints переносится:
     maxTimeRegion.Points.Remove(point)
     minTimeRegion.Points.Add(point)
     point.RegionId = minTimeRegion.Id
  5. CalculateRegionTimes пересчитывается только для двух затронутых регионов.

Если borderPoints пуст — balancing прекращается досрочно.

Полный цикл балансировки (BalanceAndCreateRegionsWithValidation)
-----------------------------------------------------------------
Выполняется в Task.Run (фоновый поток).
Источник точек — карта (LoadPointsFromMapAsync), не файл и не БД.

1. LoadPointsFromMapAsync(): обход всех оверлеев и маркеров,
   Address и BuildingType извлекаются из ToolTip маркеров через ExtractAddressFromTooltip()
   и ExtractBuildingTypeFromTooltip() (split по пробелу, поиск "Улица:", "Тип:").

2. Итерационный цикл (до maxIterations = 50):
   PerformKMeansClustering → CalculateRegionTimes → BalanceRegions → BuildConvexHulls
   → CheckPointIntersections.
   Если есть конфликтные точки → RedistributeConflictingPoints → iteration++.
   Task.Delay(100) между итерациями для освобождения потока.

3. При превышении maxIterations — предупреждение, результат всё равно применяется.

4. BuildRegionPolygons(): region.PolygonPoints = region.ConvexHullPoints.

5. SaveRegionsToDatabaseOld(): UPDATE Метки SET Участок = regionId WHERE Адрес = point.Address
   (Участок — числовое поле в Access).

6. Invoke: DisplayRegionsOnMap + DisplayStatistics.

Статистика участков (DisplayStatistics)
----------------------------------------
MessageBox с текстом для каждого участка:
  Количество адресов, Примерное время (мин), Среднее расстояние до почты (м).
Итоговые строки: среднее/макс/мин время, разница, процент балансировки
= (max - min) / avg × 100%.
