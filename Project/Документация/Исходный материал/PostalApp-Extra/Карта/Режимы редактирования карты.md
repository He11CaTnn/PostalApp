РЕЖИМЫ РЕДАКТИРОВАНИЯ КАРТЫ
============================

Класс: CreateBalancedRegions
Enum: MapMode { None, CreateMarker, MoveObject, DeleteObject, CreateNode }

Переключение режимов
--------------------
Кнопки button11–button14 включают соответствующий режим.
При повторном нажатии на активную кнопку режим отключается.
DeactivateMapMode() сбрасывает currentMapMode = None, возвращает курсор,
обнуляет selectedMarkerToMove, восстанавливает текст кнопок.
Переключение режима всегда сначала вызывает DeactivateMapMode(),
затем устанавливает новый режим.

Режим CreateMarker (button11)
------------------------------
Курсор меняется на Crosshair.
Клик по карте открывает модальную форму с полями:
  Тип здания, Улица (*обязательное), Дом, Корпус, Квартира.
Валидация: Улица не может быть пустой. Хотя бы одно из Дом/Корпус/Квартира должно быть заполнено.
При OK:
  - Ищется или создаётся оверлей "markers".
  - Создаётся серый кастомный маркер (CreateSmallCircleBitmap(Color.Gray)).
  - В Tag записывается анонимный объект: {Street, House, Corpus, Flat, BuildingType}.
  - Настраивается ToolTip (Улица, Дом, Корпус, Квартира, Тип).
После закрытия диалога (OK или Cancel) DeactivateMapMode() всегда вызывается.

Режим MoveObject (button12)
-----------------------------
Первый клик — выбор объекта:
  1. Сначала проверяется FindNearestNode() — нет ли узла участка в радиусе 10px.
     Если найден — создаётся временный GMarkerGoogle с Tag {IsNode=true, RegionId, OldPoint}.
     selectedMarkerToMove присваивается этот маркер.
  2. Если узел не найден — перебираются все маркеры всех оверлеев.
     Клик засчитывается если расстояние < 10 пикселей.
     selectedMarkerToMove присваивается найденный маркер.
  В обоих случаях курсор меняется на Crosshair.

Второй клик — перемещение:
  Если перемещается узел (IsNode в Tag):
    UpdateNodeInDatabase(regionId, oldPoint, newPoint).
    Если автооптимизация включена (checkBox1.Checked) → OptimizeSingleRegionBoundary().
    Перезагрузка участков из БД → DisplayRegionsOnMap().
  Если перемещается маркер:
    Маркер удаляется из оверлея.
    Определяется цвет: если balancedRegions != null — ищется участок через IsPointInPolygon().
    Создаётся новый маркер на новой позиции с цветом участка (или серым).
    Tag и ToolTip переносятся на новый маркер.
  selectedMarkerToMove = null, курсор возвращается.

Режим DeleteObject (button13)
------------------------------
Курсор меняется на Crosshair.
Клик:
  1. FindNearestNode() — если узел найден:
     DeleteNodeFromDatabase(regionId, nodePoint).
     Автооптимизация если checkBox1.Checked.
     Перезагрузка участков.
     Возврат.
  2. Если узел не найден — перебираются маркеры, удаляется ближайший в радиусе 10px.

Режим CreateNode (button14)
-----------------------------
Курсор меняется на Crosshair.
UpdateRegionsComboBox() заполняет comboBox1 названиями участков из БД Access.
Клик по карте:
  - Читается выбранный участок из comboBox1.
  - Из БД Access: SELECT id FROM Участки WHERE Название = ?
  - SELECT MAX(Номер) FROM Узлы WHERE Id участка = ? — определяется следующий номер.
  - INSERT INTO Узлы (id, Долгота, Широта, Id участка, Номер) VALUES (...)
    Координаты округляются до 6 знаков.
  - Автооптимизация если checkBox1.Checked.
  - Перезагрузка участков из БД → DisplayRegionsOnMap().

Автоматическая оптимизация при редактировании
----------------------------------------------
checkBox1 — «Автооптимизация границ».
При включённом флаге после каждого добавления, перемещения или удаления узла
вызывается OptimizeSingleRegionBoundary(regionId).
Метод перечитывает узлы из БД, запускает OptimizePolygonBoundary(),
удаляет старые узлы и записывает оптимизированные обратно.
