ИНИЦИАЛИЗАЦИЯ КАРТЫ
====================

Класс: CreateBalancedRegions
Метод: InitializeMap()
Библиотека: GMap.NET

Параметры GMapControl
----------------------
MapProvider             = GMapProviders.OpenCycleMap (уличный режим, OSM)
GMaps.Instance.Mode     = AccessMode.ServerAndCache (онлайн + кеш)
Position                = postOfficeLocation (Program.StartLat, Program.StartLng)
ShowCenter              = false
MinZoom                 = 5
MaxZoom                 = 18
Zoom                    = 12 (начальный)
MouseWheelZoomType      = MousePositionAndCenter
CanDragMap              = true
DragButton              = MouseButtons.Left

Начальная позиция карты
------------------------
postOfficeLocation задаётся в конструкторе как
new PointLatLng(Program.StartLat, Program.StartLng).
Program.StartLat/StartLng заполняются из ответа /api/getconfig_extra.
При неудаче — координаты Москвы (55.7522, 37.6156).
Так как postOfficeLocation задаётся в поле при объявлении класса, а не в конструкторе,
актуальные значения из Program используются только если Program.StartLat/StartLng
уже записаны к моменту создания CreateBalancedRegions.

Маркер почтового отделения
---------------------------
При DisplayRegionsOnMap и LoadFromServerAndDisplayOnMap на карте добавляется
GMarkerGoogle(postOfficeLocation, GMarkerGoogleType.red_pushpin)
с подписью "Почтовое отделение". Это ориентир для расчёта времени обхода.

Обработчик кликов
-----------------
gMapControl1.OnMapClick += GMapControl1_OnMapClick

Все клики левой кнопкой мыши по карте обрабатываются в GMapControl1_OnMapClick().
В зависимости от currentMapMode вызывается один из четырёх обработчиков:
  CreateMarker → HandleCreateMarkerClick
  MoveObject   → HandleMoveObjectClick
  DeleteObject → HandleDeleteObjectClick
  CreateNode   → HandleCreateNodeClick
При MapMode.None клики по карте не производят действий.

Кастомные иконки маркеров
--------------------------
CreateSmallCircleBitmap(color) создаёт Bitmap 16×16 пикселей:
  Прозрачный фон, закрашенный эллипс (2,2,12,12) нужного цвета,
  обводка чёрным пером толщиной 1px.
Используется для всех пользовательских маркеров: серых (неразделённых),
цветных (после балансировки или загрузки участков).

Оверлеи
--------
Карта использует два именованных оверлея, создаваемых динамически:
  "polygons" — GMapPolygon участков (закрашенные полупрозрачные, с контуром)
  "markers"  — GMarkerGoogle точек адресов, центров участков, почты

При DisplayRegionsOnMap() gMapControl1.Overlays.Clear() сбрасывает оба оверлея
и создаёт их заново. При LoadMarkersFromAddresses() также вызывается Overlays.Clear().
