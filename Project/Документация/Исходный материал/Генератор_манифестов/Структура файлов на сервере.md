СТРУКТУРА ФАЙЛОВ НА СЕРВЕРЕ
============================

Сервер: <ip_адрес> (Debian 12)
Корень обновлений PostalApp: /var/www/postalapp_updates/
Nginx отдаёт эту папку по пути /updates/ (http://<ip_адрес>/updates/)

Структура после нескольких релизов
------------------------------------

/var/www/postalapp_updates/
  manifest.json                           ← глобальный манифест (обновляется при каждом релизе)
  versions/
    v0.1.22/
      version_manifest.json               ← манифест конкретной версии
      update.zip                          ← архив файлов для автообновления
      PostalApp_Setup_v0.1.22.exe         ← установщик (опционально, если нужен с сервера)
    v0.1.21/
      version_manifest.json
      update.zip
    v0.1.20/
      ...

Корень сайта (дистрибуция): /var/www/{папка сайта}/
  assets/postalapp-extra/
    manifest.json                         ← манифест версий Extra (обновляется вручную)
    versions/
      PostalApp-Extra_Setup_v0.25.exe
      PostalApp-Extra_Setup_v0.26.exe     ← добавляется при каждом релизе

Доступные URL-адреса
--------------------
Глобальный манифест:
  http://<ip_адрес>/updates/manifest.json

Версионный манифест конкретной версии:
  http://<ip_адрес>/updates/versions/v{version}/version_manifest.json

Архив обновления:
  http://<ip_адрес>/updates/versions/v{version}/update.zip

Манифест Extra:
  http://<ip_адрес>/assets/postalapp-extra/manifest.json
  (или /assets/postalapp-extra/manifest.json через URL сайта)

Установщик Extra конкретной версии:
  http://<ip_адрес>/assets/postalapp-extra/versions/PostalApp-Extra_Setup_v{version}.exe

Формат глобального manifest.json
----------------------------------
{
  "versions":    ["0.1.22", "0.1.21", "0.1.20"],
  "downloadUrl": "http://<ip_адрес>/updates/versions/v0.1.22/update.zip",
  "fileSize":    12345678,
  "checksum":    "md5-hex"
}

versions[]   — все поддерживаемые версии, первый элемент — самая новая.
downloadUrl  — ссылка на update.zip последней версии.
fileSize     — размер update.zip в байтах.
checksum     — MD5 update.zip (проверяется клиентом после скачивания).

Формат version_manifest.json
-----------------------------
{
  "version":      "0.1.22",
  "releaseDate":  "2026-05-05",
  "releaseNotes": "Описание изменений",
  "files": [
    {"path": "PostalApp.exe", "md5": "abc123...", "size": 1642928},
    {"path": "SomeLib.dll",   "md5": "def456...", "size": 557568},
    ...
  ]
}

files[] используется:
  - Клиентом при проверке целостности (IntegrityChecker.CheckAllFiles).
  - Сервером FastAPI при валидации входящего exe_md5 (/api/getconfig, /api/checkdevice).
    Сервер ищет файл с path == "postalapp.exe" (регистронезависимо) и сравнивает md5.

Формат manifest.json Extra
---------------------------
{
  "versions": ["0.26", "0.25"]
}
Только массив версий. Ссылка на установщик строится сайтом как:
  {extraVersionBase}PostalApp-Extra_Setup_v{версия}.exe
