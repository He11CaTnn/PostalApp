ГЕНЕРАТОР МАНИФЕСТОВ (manifests.py)
=====================================

Файл: manifests.py
Язык: Python 3.x
Назначение: автоматизация подготовки файлов для выпуска новой версии PostalApp.

Что делает скрипт за один запуск
----------------------------------
1. Сканирует папку Release и вычисляет MD5 каждого файла.
2. Создаёт version_manifest.json для конкретной версии.
3. Упаковывает файлы Release в update.zip (исключая logs и отладочные файлы).
4. Опционально копирует установщик (.exe) из папки указанной в pathSetup.txt.
5. Обновляет глобальный manifest.json (добавляет новую версию первой).

Расположение файлов
--------------------
Скрипт ожидает следующую структуру вокруг себя:

  manifests.py            ← сам скрипт
  manifest.json           ← глобальный манифест (создаётся/обновляется)
  pathProject.txt         ← путь к папке Release (кеш, опционально)
  pathSetup.txt           ← путь к папке с установщиком (опционально)
  versions/
    v0.1.22/
      version_manifest.json
      update.zip
      PostalApp_Setup_v0.1.22.exe  ← если pathSetup.txt настроен

Константы
---------
VERSIONS_DIR    = {папка скрипта}/versions
MANIFEST_PATH   = {папка скрипта}/manifest.json
BASE_URL        = "http://<ip_адрес>/updates/versions/v{version}/update.zip"
EXCLUDED_DIRS   = {"logs"}
EXCLUDED_EXTS   = {".pdb", ".xml", ".log"}

Исключения синхронизированы с PostalApp_Setup.iss:
  Excludes: "logs\*,*.pdb,*.xml,*.log"

Функции
--------

md5_file(path) → str
  Вычисляет MD5-хэш файла чанками по 65536 байт.
  Возвращает hex-строку в нижнем регистре.

collect_files(release_dir) → list[dict]
  Рекурсивный обход release_dir через rglob("*").
  Исключает файлы: любая часть пути входит в EXCLUDED_DIRS (нечувствительно к регистру)
                   или расширение в EXCLUDED_EXTS.
  Возвращает список: [{"path": "rel/path", "md5": "...", "size": N}, ...]
  Разделитель пути всегда "/", даже на Windows.

create_update_zip(release_dir, out_path) → (checksum, size)
  Создаёт ZIP-архив с теми же правилами исключения что и collect_files.
  Метод сжатия: ZIP_DEFLATED.
  После создания вычисляет MD5 самого zip-файла и его размер.
  Возвращает (md5_zip, размер_байт).

Шаг 1: create_version_manifest(version, release_dir, version_dir)
------------------------------------------------------------------
Вызывает collect_files() → получает список файлов с MD5 и размерами.
Создаёт versions/v{version}/version_manifest.json:
{
  "version":      "0.1.22",
  "releaseDate":  "2026-05-05",  ← date.today()
  "releaseNotes": "",            ← заполнить вручную
  "files": [
    {"path": "PostalApp.exe", "md5": "abc123...", "size": 1642928},
    ...
  ]
}
Поле releaseNotes после генерации нужно заполнить вручную.

Шаг 2: create_zip(release_dir, version_dir)
--------------------------------------------
Создаёт versions/v{version}/update.zip.
Выводит в консоль: путь, размер в байтах, MD5 архива.
Возвращает (checksum, file_size) для передачи в шаг 3.

Шаг 2.5: copy_setup_exe(version, version_dir)
----------------------------------------------
Опциональный шаг — копирует установщик в папку версии.
Читает путь к папке с установщиками из файла pathSetup.txt.
Ищет .exe файл, содержащий version в имени.
Если найдено несколько — интерактивный выбор через ввод индекса.
При любой ошибке (файл не найден, папка недоступна) — пропускает с предупреждением.

Шаг 3: update_global_manifest(version, checksum, file_size)
------------------------------------------------------------
Обновляет manifest.json в корне рядом со скриптом.

Если manifest.json не существует — создаёт с нуля:
  {"versions": ["0.1.22"], "downloadUrl": "...", "fileSize": N, "checksum": "..."}

Если существует — обновляет:
  - Удаляет version из массива если уже есть (защита от повторного запуска).
  - Вставляет version первым элементом (versions[0] = последняя версия).
  - Обновляет downloadUrl, fileSize, checksum.
  - Старые версии в массиве сохраняются — клиент проверяет поддержку по этому списку.

downloadUrl для новой версии:
  http://<ip_адрес>/updates/versions/v{version}/update.zip

Чтобы убрать поддержку старой версии — нужно вручную удалить её из versions[].

Файл pathProject.txt
---------------------
Кеш пути к папке Release. При запуске:
  - Если файл существует и не пуст — предлагает использовать сохранённый путь.
  - Enter без ввода — использует сохранённый.
  - Ввод нового пути — использует новый (но не перезаписывает файл автоматически).
  - Если файл не существует — запрашивает путь.

Файл pathSetup.txt
-------------------
Содержит путь к папке где лежит скомпилированный установщик (.exe).
Читается в copy_setup_exe(). Если файл отсутствует или пуст — шаг 2.5 пропускается.
Пример содержимого:
  Project\PostalAppProject\Интерфейс\bin\Release\Setup\PostalApp
