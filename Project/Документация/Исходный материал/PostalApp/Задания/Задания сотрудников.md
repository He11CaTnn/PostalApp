ЗАДАНИЯ СОТРУДНИКОВ (TaskOnEmployee)
=====================================

Класс: TaskOnEmployee (статический)
Файл: TaskOnEmployee.cs

Назначение
----------
Управление заданиями, выданными сотрудникам: отображение, смена статуса,
автоматическая проверка новых заданий по таймеру.

Статусы задания
---------------
_taskStatus[0] = "Новое"       — создано, не открыто сотрудником.
_taskStatus[1] = "Принято"     — сотрудник открыл задание.
_taskStatus[2] = "В процессе"  — сотрудник начал выполнение.
_taskStatus[3] = "Выполнено"   — задание завершено.

Внутреннее состояние
---------------------
_tasks        — List<TaskViewModel> (не используется активно в логике, резервируется).
_selectedTask — TaskViewModel текущего выбранного задания.

TaskViewModel — вложенный класс:
  Task     — DataBase.Tasks
  Employee — DataBase.Employees

Автоматическая проверка новых заданий
---------------------------------------
Метод UpdateTasksTimer(timer, cuiPictureBox, pictureBox):
  Создаёт System.Windows.Forms.Timer с интервалом _timeUpdateTasks = 5000 мс (5 секунд).
  При каждом тике вызывается AutoUpdateTasks(cuiPictureBox, pictureBox).

AutoUpdateTasks:
  Запрашивает задания текущего сотрудника со статусом "Новое".
  Если таких заданий > 0 — иконка задач меняется на «с восклицательным знаком» (Resources.задачи_с_воскл).
  Иначе — обычная иконка (Resources.задачи).
  При ошибке соединения — pictureBox (индикатор ошибки) становится видимым.

Пометка задания как "Принято" (MarkAsAcceptedIfNew):
  Вызывается когда пользователь открывает задание со статусом "Новое".
  Обновляет статус в БД на "Принято" и обновляет строку в DataGridView.
  После обновления проверяет, есть ли ещё "Новые" задания — если нет, возвращает обычную иконку.

Обновление выбранного задания (UpdateSelectedTask):
  Загружает актуальные данные задания и сотрудника из БД.
  Обновляет _selectedTask.
  Если передан DataGridView — ищет строку по Id и обновляет ячейку «Статус».

Визуальное отображение статуса (VisualChangedStatus):
  Меняет цвет, текст и состояние кнопки действия в зависимости от статуса:
    Новое / Принято:   кнопка «Начать задание» (синий контур, прозрачный фон).
    В процессе:        кнопка «Выполнить задание» (синий фон, белый текст).
    Выполнено:         кнопка «Задание выполнено», Enabled = false.
  Также заполняет: tasksTextBox (текст задания), tasksLabelStatus (статус),
  tasksDatePickerIssue (дата выдачи), tasksDatePickerDelivery (дата сдачи).

Смена статуса (ClickTasksButton):
  Если текущий статус "Новое" или "Принято" → новый статус "В процессе".
  Если "В процессе" → "Выполнено".
  Порядок действий:
    1. Блокировка кнопки, текст «Подождите».
    2. UPDATE статуса в БД.
    3. UpdateSelectedTask() — обновление данных.
    4. VisualChangedStatus() — обновление UI кнопки.
    5. Разблокировка кнопки.
    6. ShowInfo() с уведомлением.

Инициализация ComboBox фильтра (InitializeTaskComboBox):
  Перебирает видимые столбцы DataGridView и добавляет их заголовки в cuiComboBox.
  Добавляет последним пункт «Показывать всё».
  Устанавливает выбор на последний пункт.
