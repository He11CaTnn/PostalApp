ПОИСК И ФИЛЬТРАЦИЯ (SearchFilter)
==================================

Класс: SearchFilter<T> (generic)
Файл: SearchFilter.cs

Назначение
----------
Универсальный фильтр для любой таблицы PostgreSQL. Принимает имя C#-свойства
и строку поиска, формирует условие для PgQuery<T> с учётом типа поля.

Состояние
---------
FilterColumn — имя C#-свойства (не столбца БД).
FilterValue  — искомая строка.
IsActive     — true если оба поля непустые.

Установка и сброс
-----------------
SetFilter(columnPropName, value) — устанавливает фильтр, значение тримируется.
Clear() — обнуляет оба поля.

ApplyToQuery(query) — применение фильтра
-----------------------------------------
1. Если фильтр неактивен — возвращает query без изменений.
2. Через GetDbColumnName() резолвится DbColumnAttribute.ColumnName по имени свойства.
3. Получается PropertyInfo для определения типа данных.

Особый случай — поле "Login" у Employees:
  Логин хранится в отдельной таблице; фильтрация через JOIN не поддерживается ORM.
  ShowWarning уведомляет пользователя, запрос не модифицируется.

Логика по типу данных:

DateTime / DateTime?:
  Поиск подстроки в текстовом представлении даты через CAST(столбец AS TEXT).
  PostgreSQL хранит timestamp в формате "YYYY-MM-DD HH:MM:SS+TZ".
  Входная строка разбивается по точке:
    1 часть (напр. "30")     → ILIKE "%-30%" (день месяца)
    2 части (напр. "30.12")  → ILIKE "%-12-30%" (день и месяц)
    3 части (напр. "30.12.2025") → ILIKE "2025-12-30%" (полная дата)
  Используется FilterWithCast().

float / int / double / decimal / long / short:
  Точное числовое равенство (Filter op "=").
  Парсинг float с поддержкой как точки, так и запятой в качестве разделителя.
  При нечисловом вводе — подставляется -9999999 (гарантированно пустой результат).

Текстовые поля (всё остальное):
  Filter op "ILIKE" со значением "%строка%" — поиск подстроки регистронезависимо.
  Поддерживает кириллицу при Encoding=UTF8 в строке подключения.

GetDbColumnName(propertyName):
  Рефлексия: ищет DbColumnAttribute на свойстве типа T и возвращает ColumnName.
  Если атрибут не найден — возвращает имя свойства как есть.
