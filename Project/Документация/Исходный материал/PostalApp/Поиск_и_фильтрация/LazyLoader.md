ЛЕНИВАЯ ЗАГРУЗКА (LazyLoader)
==============================

Класс: LazyLoader<T> (generic)
Файл: LazyLoader.cs

Назначение
----------
Постраничная (batch) загрузка записей из PostgreSQL. Загружает данные порциями
по запросу (при прокрутке, пагинации и т.д.) вместо единовременного получения
всей таблицы. Работает с любым типом T через PgQuery<T>.

Зависимости
-----------
Принимает SearchFilter<T> в конструкторе. Каждый batch-запрос применяет
текущее состояние фильтра через _searchEngine.ApplyToQuery().

Параметры
---------
batchSize — количество записей в одной порции (по умолчанию 50).
_currentCount — общее количество уже загруженных записей (смещение для следующего запроса).

Состояние
---------
IsEndOfData — true если последний batch вернул 0 записей (данные исчерпаны).
IsLoading   — true пока выполняется асинхронный запрос (защита от параллельных вызовов).

LoadNextBatchAsync()
--------------------
1. Если IsLoading или IsEndOfData — возвращает пустой список.
2. IsLoading = true.
3. Формируется запрос:
   DataBase._client.From<T>()
   → ApplyToQuery() (применяет активный поисковый фильтр)
   → .Range(_currentCount, _currentCount + _batchSize - 1)
   → .Order("id", ascending: true)
4. Выполняется запрос .Get().
5. Если Models пуст — IsEndOfData = true.
   Иначе — _currentCount += records.Count.
6. IsLoading = false (в finally).
7. Возвращает список загруженных записей.

Reset()
-------
Сбрасывает _currentCount = 0, IsEndOfData = false, IsLoading = false.
Должен вызываться при смене поискового фильтра, чтобы следующий batch
начался с начала с новыми условиями.

GetTotalLoaded()
----------------
Возвращает _currentCount — количество суммарно загруженных записей.

Ограничения
-----------
Сортировка жёстко привязана к полю "id" по возрастанию. Это предполагает
наличие столбца "id" в каждой таблице (что выполняется — все таблицы имеют
первичный ключ "id" типа Guid).
