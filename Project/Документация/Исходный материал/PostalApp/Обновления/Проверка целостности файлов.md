ПРОВЕРКА ЦЕЛОСТНОСТИ ФАЙЛОВ
============================

Классы: IntegrityChecker (статический), IntegrityCheckForm
Файлы: IntegrityChecker.cs, IntegrityCheckForm.cs

Назначение
----------
Позволяет пользователю вручную проверить все файлы приложения на соответствие
эталонным MD5-хэшам из версионного манифеста. При обнаружении проблем предлагает
восстановление или обновление.

Модели данных
-------------
FileStatus (enum): OK, Missing, Corrupted.

FileIntegrityResult:
  Path        — относительный путь файла (как в манифесте)
  Status      — результат проверки
  ExpectedMd5 — эталонный MD5 из манифеста
  ActualMd5   — реальный MD5 файла (пустая строка если файл отсутствует)
  StatusText  — строковое представление статуса на русском

IntegrityReport:
  Results         — полный список FileIntegrityResult
  TotalCount      — общее число проверенных файлов
  OkCount         — кол-во файлов со статусом OK
  MissingCount    — кол-во отсутствующих
  CorruptedCount  — кол-во повреждённых
  HasErrors       — true если есть Missing или Corrupted
  BadFiles        — IEnumerable только проблемных файлов

IntegrityProgress (struct):
  Current  — текущий номер файла
  Total    — общее количество файлов
  FileName — имя проверяемого файла

Процесс проверки (IntegrityChecker.CheckAllFiles)
---------------------------------------------------
1. Скачивает version_manifest.json для текущей версии через UpdateManager.GetVersionManifest().
2. Перебирает список файлов из манифеста.
3. Для каждого файла:
   а) Сообщает прогресс через IProgress<IntegrityProgress>.
   б) Каждые 5 файлов вызывает Task.Delay(1) для освобождения UI-потока.
   в) Проверяет существование файла: Path.Combine(Application.StartupPath, entry.Path).
   г) Если файл отсутствует — статус Missing.
   д) Если файл существует — MD5 вычисляется в Task.Run() (фон, не вешает UI).
      Сравнивается с entry.Md5 (OrdinalIgnoreCase). Результат: OK или Corrupted.
4. Возвращает IntegrityReport.

IntegrityCheckForm — последовательность
-----------------------------------------
Открывается из StartupForm кнопкой «Восстановить файлы» (при 403 от сервера)
или из меню приложения.

OnLoad → RunIntegrityCheck():
  1. Загрузка версионного манифеста (с обработкой ошибки).
  2. Проверка всех файлов с прогресс-баром и счётчиком.
  3. Проверка наличия обновлений (CheckForUpdates).
  4. ShowResults() — отображение итогов и конфигурирование кнопок.

Сценарии кнопок в ShowResults():
  A: Есть ошибки + есть обновление  → [Обновить до vX] + [Восстановить текущую]
  B: Есть ошибки + нет обновления   → [Восстановить файлы]
  C: Нет ошибок + есть обновление   → [Обновить до vX] + [Закрыть]
  D: Нет ошибок + нет обновления    → [Закрыть]

Восстановление текущей версии (DoReinstallCurrent):
  Скачивает http://<ip_адрес>/updates/versions/v{version}/update.zip,
  создаёт временный UpdateInfo с этим URL и вызывает UpdateManager.ApplyUpdate().
  После успеха показывает кнопку «Перезапустить сейчас».

Обновление (DoUpdate):
  Скачивает архив из _updateInfo.DownloadUrl и применяет через UpdateManager.ApplyUpdate().

После успешного Apply кнопка «Перезапустить сейчас» закрывает все формы и вызывает
Program.AppExit().
