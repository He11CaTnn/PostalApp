СИСТЕМА ОБНОВЛЕНИЙ
==================

Класс: UpdateManager (статический)
Файл: UpdateManager.cs

Назначение
----------
Управление жизненным циклом обновлений: проверка наличия, скачивание архива,
верификация MD5, применение через bat-скрипт с перезапуском приложения.

Версии
------
Текущая версия берётся из Program.version через Regex (\d+\.\d+\.\d+).
Сравнение версий: IsNewerVersion(current, candidate) — посегментное сравнение
трёх числовых компонентов. Возвращает true если candidate строго новее current.

Манифесты
---------
Подробно описаны в файле «Манифесты версий.txt».

Проверка обновлений (CheckForUpdates)
---------------------------------------
1. FetchManifest() — скачивает и кэширует глобальный манифест.
2. Сравнивает текущую версию с versions[0] (последняя версия).
   IsUpdateAvailable = versions[0] строго новее текущей.
3. Проверяет поддержку: IsCurrentVersionSupported = текущая версия содержится в versions[].
4. Если обновление доступно — скачивает ReleaseNotes из version_manifest.json последней версии.

Скачивание обновления (DownloadUpdate)
---------------------------------------
Метод: DownloadUpdate(info, progress)

1. Целевой путь: %TEMP%\postalapp_update_{version}.zip
2. HTTP GET на info.DownloadUrl через GetAsync с ResponseHeadersRead
   (позволяет отслеживать прогресс без буферизации всего тела).
3. Буфер 8192 байта, скачивается потоками.
4. Progress<int> сообщает процент скачивания.
5. После скачивания: если info.Checksum не пустой — вычисляется MD5 файла и
   сравнивается с Checksum. Несовпадение → файл удаляется, возвращается false.
6. Таймаут: 15 минут.

Применение обновления (ApplyUpdate)
-------------------------------------
Решаемая проблема: нельзя перезаписать DLL и EXE пока они загружены процессом.

Метод: ApplyUpdate(zipPath)

1. Распаковывает zip во временную папку %TEMP%\postalapp_update_temp.
2. Обходит все файлы в temp-папке, пропуская:
   - config.dat (пользовательские данные)
   - файлы из папки logs\
3. Генерирует bat-скрипт (кодировка cp866):
   - Цикл ожидания завершения текущего процесса (по PID через tasklist).
   - Создание отсутствующих директорий (mkdir).
   - Копирование каждого файла из temp в папку приложения (copy /Y).
   - Удаление временной папки (rd /S /Q).
   - Запуск PostalApp.exe (start).
   - Самоудаление bat-файла (del "%~f0").
4. Запускает cmd.exe /C "{batchPath}" скрытно (WindowStyle.Hidden, CreateNoWindow).
5. Удаляет скачанный zip.
6. Возвращает true — вызывающий код (StartupForm) обязан сразу вызвать Program.AppExit().

Лог изменений (GetChangelog)
------------------------------
Принимает список versions[] и fromVersion (текущая).
Итерирует versions[] по порядку, скачивает version_manifest.json для каждой версии
до тех пор пока не встретит fromVersion. Возвращает список VersionInfo
(version, releaseDate, releaseNotes) для отображения в UI.

Инвалидация кэша
----------------
InvalidateCache() обнуляет _cachedManifest.
Вызывается в Step2_CheckUpdates() перед повторной проверкой обновлений после входа,
чтобы не использовать данные, полученные на этапе 0 (до входа).
