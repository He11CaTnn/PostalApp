МАНИФЕСТЫ ВЕРСИЙ
================

Назначение
----------
Сервер предоставляет два типа JSON-файлов: глобальный манифест и версионный манифест.
Оба используются как клиентом, так и сервером FastAPI для управления обновлениями
и проверкой целостности.

Глобальный манифест
--------------------
URL: http://<ip_адрес>/updates/manifest.json
На сервере: /var/www/postalapp_updates/manifest.json

Формат:
{
  "versions":    ["0.1.22", "0.1.21", "0.1.20"],
  "downloadUrl": "http://<ip_адрес>/updates/versions/v0.1.22/update.zip",
  "fileSize":    12345678,
  "checksum":    "md5-hex-строка"
}

Семантика:
  versions[]   — полный список поддерживаемых версий. Первый элемент (versions[0]) —
                 самая новая версия. Версия считается поддерживаемой если она есть в
                 этом массиве; если нет — сервер вернёт 426, клиент бросит VersionTooOldException.
  downloadUrl  — прямая ссылка для скачивания zip-архива последней версии.
  fileSize     — размер архива в байтах (не используется активно на клиенте).
  checksum     — MD5-хэш архива для верификации после скачивания.

Парсинг: UpdateManager.ParseManifest() использует Regex для извлечения значений
(без JSON-десериализатора).

Версионный манифест
--------------------
URL: http://<ip_адрес>/updates/versions/v{version}/version_manifest.json
На сервере: /var/www/postalapp_updates/versions/v{version}/version_manifest.json

Формат:
{
  "version":      "0.1.22",
  "releaseDate":  "2026-04-26",
  "releaseNotes": "Описание изменений",
  "files": [
    {"path": "PostalApp.exe", "md5": "abc123...", "size": 1642928},
    {"path": "SomeLib.dll",   "md5": "def456...", "size": 557568}
  ]
}

Использование на клиенте:
  - UpdateManager.GetVersionManifest(version) → List<VersionFileEntry> (только files[]).
  - UpdateManager.GetVersionInfo(version) → VersionInfo (version, releaseDate, releaseNotes).
  - IntegrityChecker.CheckAllFiles() скачивает files[] и сверяет MD5 каждого файла.

Использование на сервере (FastAPI):
  - get_exe_md5_from_version_manifest() ищет файл с path == "postalapp.exe" (регистронезависимо)
    и возвращает его md5 для сравнения с md5, переданным клиентом при входе.
  - check_version_and_integrity() вызывает эту функцию и сравнивает хэши.

Кэширование
-----------
Глобальный манифест кэшируется в _cachedManifest после первой загрузки.
Версионные манифесты не кэшируются — скачиваются при каждом обращении.
