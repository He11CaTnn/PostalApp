ФОРМА ПРОВЕРКИ ЦЕЛОСТНОСТИ (IntegrityCheckForm)
================================================

Файл: IntegrityCheckForm.cs

Назначение
----------
Интерактивный инструмент проверки целостности файлов приложения и управления обновлениями.
Открывается из StartupForm при обнаружении повреждённых файлов (HTTP 403 от сервера),
либо может быть вызвана вручную.

Последовательность при открытии (OnLoad → RunIntegrityCheck)
-------------------------------------------------------------
1. Загрузка версионного манифеста для текущей версии.
   При неудаче: статус «Не удалось загрузить манифест», manifestOk = false.

2. Если манифест загружен: CheckAllFiles() с прогрессом.
   Прогресс обновляет статус и счётчик ("N из M файлов").
   Результат: IntegrityReport (статистика OK/Missing/Corrupted).

3. CheckForUpdates() — параллельно с итогами целостности проверяется
   наличие новых версий.

4. ShowResults() — построение итогового UI.

Итоговый экран (ShowResults)
-----------------------------
Панель _resultsPanel становится видимой и отображает:
  _lblResultsOk  — "✓  В порядке: N из M"
  _lblResultsBad — "✕  Проблем: N" (красный) или "✓  Проблем нет" (зелёный)
  _filesListBox  — список проблемных файлов с указанием статуса, если HasErrors.

Если есть обновление — к тексту _lblResultsBad добавляется "| ↓ vX доступна".

Конфигурация кнопок:
  Ошибки + обновление:  [Обновить до vX] + [Восстановить текущую]
  Только ошибки:        [Восстановить файлы]
  Только обновление:    [Обновить до vX] + [Закрыть]
  Всё в порядке:        [Закрыть]

Кнопки конфигурируются через ConfigureButton() — метод записывает Func<Task>
в Button.Tag и подписывает UniversalButtonClick, который вызывает этот делегат.
Это позволяет менять действие кнопки без создания новых обработчиков.

Действия кнопок
---------------
Обновление (DoUpdate):
  DownloadUpdate(_updateInfo) → ApplyUpdate() → ShowRestartButton().

Восстановление (DoReinstallCurrent):
  Формирует URL: http://81.90.25.60/updates/versions/v{currentVersion}/update.zip.
  Создаёт временный UpdateInfo только с этим URL.
  DownloadUpdate(tempInfo) → ApplyUpdate() → ShowRestartButton().

После успешного Apply показывается кнопка «Перезапустить сейчас»:
  Закрывает все открытые формы через Application.OpenForms,
  затем Program.AppExit().

Состояние кнопок
-----------------
DisableAllButtons() / EnableAllButtons() — блокируют/разблокируют кнопки
во время асинхронных операций скачивания и применения.

Позиционирование кнопок
------------------------
CenterOneButton(btn)  — центрирует одну кнопку по горизонтали на y=418.
CenterTwoButtons()    — размещает две кнопки с отступом 20px между ними, центрированно.

Информация о версии
-------------------
_lblVersion и _lblAppInfo заполняются из Program.version при инициализации.
