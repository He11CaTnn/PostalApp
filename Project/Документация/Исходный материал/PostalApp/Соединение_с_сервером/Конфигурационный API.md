КОНФИГУРАЦИОННЫЙ API
====================

Назначение
----------
Клиент не хранит строку подключения к PostgreSQL локально. Вместо этого при каждом
запуске он получает её с конфигурационного сервера, предварительно пройдя аутентификацию.
Сервер также возвращает координаты почтового отделения для центрирования карты.

Адрес сервера
-------------
Все запросы идут на https://<ip_адрес> (прямой IP, без DNS).
HTTPS обязателен; SSL-сертификат верифицируется через pinning (см. SSL Pinning.txt).

Эндпоинты
---------
POST /api/getconfig
  Назначение: ручной вход — логин и пароль.
  Тело запроса (JSON):
    login     — email пользователя
    password  — пароль открытым текстом
    version   — текущая версия приложения (x.y.z, извлекается из Program.version)
    exe_md5   — MD5-хэш файла PostalApp.exe в нижнем регистре

POST /api/checkdevice
  Назначение: автовход по ID материнской платы.
  Тело запроса (JSON):
    motherboard_id — серийный номер материнской платы из WMI Win32_BaseBoard
    version        — текущая версия приложения
    exe_md5        — MD5-хэш PostalApp.exe

Формат ответа (оба эндпоинта, при успехе)
------------------------------------------
HTTP 200, JSON:
  config — строка подключения вида "ip|port|database|user|password"
  lat    — широта (опционально)
  lng    — долгота (опционально)

Если lat/lng отсутствуют или некорректны, карта использует координаты Москвы по умолчанию.

Коды ошибок
-----------
HTTP 401 — Неверный логин или пароль (для /api/getconfig) /
           Устройство не найдено или PermanentAccess = false (для /api/checkdevice)
           Клиент бросает UnauthorizedAccessException (/api/getconfig) или возвращает null (/api/checkdevice).

HTTP 403 — Целостность файлов нарушена (MD5 exe не совпадает с эталонным).
           Клиент бросает IntegrityFailedException.

HTTP 426 — Версия приложения не входит в список поддерживаемых.
           Клиент бросает VersionTooOldException.

HTTP 429 — Превышен лимит попыток входа с данного IP.
           Тело содержит JSON: {"detail":{"reason":"rate_limit","retry_after":N}}
           Клиент парсит retry_after и бросает RateLimitException(N).

Разбор ответа
-------------
Парсинг JSON производится вручную через Regex, без десериализации объектов:
  - Поле config извлекается регулярным выражением \"config\"\s*:\s*\"([^\"]+)\"
  - Поля lat и lng извлекаются аналогично
  - Поле retry_after извлекается из тела 429

Строка config разбивается методом ServerConfig.FromConfigString() по символу '|':
  parts[0] → ServerIP
  parts[1] → ServerPort (int.Parse)
  parts[2] → ServerDatabase
  parts[3] → ServerUser
  parts[4] → ServerPassword

Полученные значения записываются в статические свойства Program (ServerIP, ServerPort и т.д.)
для дальнейшего использования при подключении к PostgreSQL.

Таймаут
-------
/api/getconfig   — 15 секунд
/api/checkdevice — 10 секунд
При превышении таймаута или недоступности сервера бросается HttpRequestException,
которое перехватывается и отображается пользователю как ошибка соединения.

MD5 exe-файла
-------------
Метод GetExeMd5() вычисляет MD5 файла PostalApp.exe из директории запуска приложения.
Если файл не найден (например, запуск из IDE под именем Интерфейс.exe),
метод возвращает пустую строку. Сервер в таком случае отклонит запрос с 403.
