ИСКЛЮЧЕНИЯ СОЕДИНЕНИЯ С СЕРВЕРОМ
================================

Назначение
----------
SecureConfig использует собственные исключения для разграничения типов отказов
при обращении к конфигурационному серверу. Это позволяет StartupForm реагировать
на каждый сценарий отдельно и показывать соответствующий UI.

Перечень исключений
-------------------

VersionTooOldException
  Файл: SecureConfig.cs
  Наследует: Exception
  Когда бросается: сервер вернул HTTP 426 (Upgrade Required).
  Смысл: версия приложения отсутствует в списке поддерживаемых версий сервера.
  Обработка: StartupForm показывает кнопку обновления. Вход в систему невозможен
             до установки актуальной версии.

IntegrityFailedException
  Файл: SecureConfig.cs
  Наследует: Exception
  Когда бросается: сервер вернул HTTP 403 (Forbidden).
  Смысл: MD5-хэш PostalApp.exe, переданный при входе, не совпадает с хэшем,
         хранящимся в version_manifest.json на сервере для данной версии.
         Означает модификацию или повреждение исполняемого файла.
  Обработка: StartupForm показывает кнопку восстановления файлов.
             Вход заблокирован.

RateLimitException
  Файл: SecureConfig.cs
  Наследует: Exception
  Свойство: RetryAfter (int) — количество секунд до разблокировки.
  Когда бросается: сервер вернул HTTP 429 (Too Many Requests).
  Смысл: превышен лимит попыток входа с данного IP-адреса.
         Для ручного входа — лимит 5 попыток за 60 секунд.
         Для автовхода — IP заблокирован по лимиту ручного входа (rate limit проверяется
         первым, до лимита автовхода).
  Обработка: StartupForm запускает таймер обратного отсчёта,
             блокирует поле ввода и кнопку «Войти» на RetryAfter секунд.

UnauthorizedAccessException (стандартное .NET)
  Когда бросается: сервер вернул HTTP 401 при вызове FetchConfigFromServer().
  Смысл: неверный логин или пароль.
  Обработка: StartupForm показывает сообщение об ошибке, не скрывает форму входа.
  Примечание: FetchConfigByMotherboardId() при 401 возвращает null вместо
              исключения — устройство просто не найдено.

Общий Exception
  Когда: HttpRequestException (нет соединения, таймаут), неожиданный HTTP-код,
         ошибки разбора ответа.
  Обработка: StartupForm перехватывает и показывает общее сообщение об ошибке
             подключения.

Принцип обработки в StartupForm
--------------------------------
HandleLoginClick() и HandleDeviceAutoLogin() содержат последовательные catch-блоки
для каждого типа исключения в порядке специфичности:
  RateLimitException → запуск таймера
  VersionTooOldException → кнопка обновления
  IntegrityFailedException → кнопка восстановления
  UnauthorizedAccessException → сообщение о неверных данных
  Exception → общая ошибка соединения
