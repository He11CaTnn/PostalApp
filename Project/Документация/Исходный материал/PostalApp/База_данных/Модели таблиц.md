МОДЕЛИ ТАБЛИЦ БАЗЫ ДАННЫХ
=========================

Класс: DataBase (статический)
Файл: DataBase.cs

Содержит статический клиент PgClient (_client), метод подключения и вложенные
классы-модели для каждой таблицы PostgreSQL.

Подключение
-----------
TryConnectAsync() — создаёт PgClient из статических свойств Program
(ServerIP, ServerPort, ServerDatabase, ServerUser, ServerPassword) и выполняет
тестовый SELECT к таблице «тест». Бросает исключение при любой ошибке.

Строка подключения формируется как:
  Host=...; Port=...; Database=...; Username=...; Password=...; Encoding=UTF8; Client Encoding=UTF8;

Таблица «Сотрудники» → класс Employees
  id             (Guid, PK)
  ФИО            (string)
  Роль           (string) — одно из: «Почтальон», «Оператор», «Руководитель подписок», «Директор»
  Id логина      (Guid)   — внешний ключ к таблице Логин
  Дата создания  (DateTime)
  Устройства     (string[]) — массив (не используется активно в логике)

Таблица «Логин» → класс Login
  id      (Guid, PK)
  Почта   (string) — email, уникальный идентификатор для входа
  Пароль  (string) — PBKDF2-SHA256 хэш в Base64

Таблица «Метки» → класс Markers
  id              (Guid, PK)
  Широта          (double)
  Долгота         (double)
  Тип здания      (string) — «Частный дом», «Многоквартирный дом», «Здание организаций», «Post Office»
  Улица           (string)
  Дом             (string)
  Корпус          (string)
  Квартира        (string)
  Id участка      (Guid)   — внешний ключ к таблице Участки
  Id читателей    (string) — строка с Guid-ами через запятую

Таблица «Участки» → класс Regions
  id            (Guid, PK)
  Название      (string)
  Цвет          (string) — hex-код цвета (#RRGGBB или RRGGBB)
  Id сотрудника (Guid)   — внешний ключ к таблице Сотрудники

Таблица «Узлы» → класс Nodes
  id          (Guid, PK)
  Широта      (double)
  Долгота     (double)
  Id участка  (Guid) — внешний ключ к таблице Участки
  Номер       (int)  — порядковый номер вершины полигона (для правильной отрисовки)

Таблица «Задания» → класс Tasks
  id                  (Guid, PK)
  Id сотрудника       (Guid)
  Текст               (string)
  Статус              (string) — «Новое», «Принято», «В процессе», «Выполнено»
  Дата выдачи         (DateTime)
  Дата завершения     (DateTime)
  Прикрепленные метки (string) — Guid-ы меток через запятую

Таблица «Издания» → класс Editions
  id                                        (Guid, PK)
  Индекс                                    (string) — каталожный индекс издания
  Название                                  (string)
  Тип издания                               (string)
  Минимальный срок подписки                 (float) — в месяцах
  Минимальная цена подписки на дом          (float)
  Минимальная цена подписки на почтовый ящик (float)
  Максимальный срок подписки                (float)
  Максимальная цена подписки на дом         (float)
  Максимальная цена подписки на почтовый ящик (float)

Таблица «Подписки» → класс Subscriptions
  id                (Guid, PK)
  Срок подписки     (string)
  Цена подписки     (string)
  Комплекты         (int)
  Дата оформления   (DateTime)
  Id издания        (string) — индекс издания (не UUID, а каталожный номер)

Таблица «Читатели» → класс Readers
  id                    (Guid, PK)
  ФИО                   (string)
  Id активных подписок  (string) — Guid-ы подписок через запятую

Таблица «Устройства» → класс Devaices
  id                    (Guid, PK)
  Id сотрудника         (string) — Guid в строковом представлении
  ip                    (string) — внешний IP
  Id материнской платы  (string) — серийный номер из WMI Win32_BaseBoard
  Название устройства   (string) — hostname
  Местоположение        (string) — город, страна из ip-api.com
  Постоянный доступ     (bool)   — true = автовход разрешён
  Последний вход        (DateTime, UTC)

Таблица «тест» → класс test
  число (string, PK)
  Используется исключительно для проверки живости соединения в TryConnectAsync().
