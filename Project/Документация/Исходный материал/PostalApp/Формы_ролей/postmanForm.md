ФОРМА ПОЧТАЛЬОНА (postmanForm)
===============================

Файл: postmanForm.cs
Роль пользователя: Почтальон

Общая структура
---------------
Форма состоит из двух панелей, между которыми переключается боковое меню:
  mapPanel    — карта с маршрутизацией
  tasksPanel  — список заданий

Панель: Карта
-------------
Инициализация:
  Map.InitializeMap(gMapControl) — настройка карты GMap.NET.
  Map.RefreshMap(gMapControl) — загрузка маркеров и участков для текущего пользователя.
  Маркеры загружаются только из участков, назначенных текущему почтальону
  (CurrentUser.RegionIds). Директорский «вид всех участков» недоступен.

Управление слоями:
  gMapCheckBox3_1 — «Автоматический режим»: при включении блокирует ручные чекбоксы
    и передаёт управление видимостью слоёв в Map.ApplyAutoZoomSettings(),
    который скрывает/показывает маркеры и полигоны в зависимости от уровня зума.
  gMapCheckBox3_2 — видимость полигонов участков (_regionsOverlay).
  gMapCheckBox3_3 — видимость границ (_boundsOverlay).
  gMapCheckBox3_4 — видимость маркеров адресов (_homesOverlay).

Переключение режима карты:
  gMapButton3_1 — уличный режим (OpenCycleMap).
  gMapButton3_2 — спутниковый режим (GoogleSatelliteMap).

Масштаб:
  Кнопки + и − изменяют gMapControl.Zoom на ±1.
  Кнопка «Вернуться» устанавливает gMapControl.Position = Map.startPosition.

Выделение маркеров:
  Двойной клик по маркеру — переключает выделение (SelectedMarkers.SelectMarker /
  RemoveMarkerSelection). Одиночный клик работает только если уже есть выделение
  (_selectionMode == true). Счётчик выделенных маркеров отображается в gMapButton4_1.

Панель маршрута (gMapPanel4):
  Выезжает/прячется анимационным таймером routeTimer.
  gMapButton4_1 — кнопка «Построить маршрут» (счётчик выделенных маркеров):
    Если выделенных маркеров нет — маршрут строится по всем маркерам на карте.
    В список SelectedMarkers._points добавляется маркер почтового отделения.
    Route.BuildRoute() строит маршрут через OSM Routing и отрисовывает линии.
    Число точек сохраняется в routeMarkers, выделение сбрасывается.
  gMapButton4_2 — сбросить выделение (сохраняя маршрут).
  gMapButton4_3 — сбросить маршрут и выделение полностью, очистить _routesOverlay.

Построение маршрута по заданию (button1):
  Активируется только при наличии AttachedMarkers в выбранном задании.
  Парсит строку AttachedMarkers (Guid через запятую) посимвольно.
  Для каждого Guid ищет маркер в _homesOverlay по Tag.
  Если маркер не найден на карте — загружает его из БД и добавляет через
  Marker.AddMarkerToMap().
  После формирования списка добавляет маркер почтового отделения и вызывает
  routeConstructionButton1_Click → Route.BuildRoute().

Панель: Задания
---------------
Таблица tasksDataGridView инициализируется через DataTables.InitializeTasksTable().
Загружаются только задания текущего пользователя (item.IdEmployee == CurrentUser.Employee.Id).

Ленивая загрузка (LazyLoader):
  Данные подгружаются пачками по 50 записей через _loaderTasks.LoadNextBatchAsync().
  При прокрутке до последних 10 строк таблицы запускается следующий batch.
  Дебаунс-таймер 100 мс предотвращает множественные параллельные запросы.

Поиск и фильтрация:
  SearchTasksComboBox1 — выбор столбца фильтрации (только видимые столбцы).
  SearchTasksTextBox1 + кнопка — применить фильтр через SearchFilter<Tasks>.
  «Показывать всё» — сбросить фильтр, перезагрузить таблицу.

Автоматическая проверка новых заданий:
  TaskOnEmployee.UpdateTasksTimer() запускает таймер с интервалом 5 секунд.
  При наличии новых заданий иконка меню меняется на вариант с восклицательным знаком.

Клик по строке задания:
  Загружает задание из БД по id из скрытой ячейки.
  TaskOnEmployee.UpdateSelectedTask() обновляет _selectedTask.
  TaskOnEmployee.VisualChangedStatus() обновляет текст, статус и состояние кнопки действия.
  Если у задания есть AttachedMarkers — кнопка button1 разблокируется.
  TaskOnEmployee.MarkAsAcceptedIfNew() при статусе «Новое» автоматически переводит
  задание в «Принято» и обновляет иконку.

Смена статуса задания (tasksButton3_1):
  TaskOnEmployee.ClickTasksButton() — «В процессе» или «Выполнено» в зависимости
  от текущего статуса.

Кнопка проверки целостности:
  cuiPanel1_Click → открывает IntegrityCheckForm.
