ФОРМА ДИРЕКТОРА (directorForm)
================================

Файл: directorForm.cs
Роль пользователя: Директор

Общая структура
---------------
Три панели, переключаемые боковым меню:
  mapPanel          — карта
  tasksPanel        — задания
  registrationPanel — управление сотрудниками

Панель: Карта
-------------
Идентична postmanForm, за одним исключением:

1. Загружаются ВСЕ маркеры и ВСЕ участки без фильтрации по RegionIds.

Панель: Задания
---------------
Загружаются задания ВСЕХ сотрудников (не только текущего пользователя).
LazyLoader, дебаунс-таймер и поиск/фильтрация — идентичны postmanForm.

Клик по строке задания дополнительно:
  LoadRoleByEmployeeId(task.IdEmployee) — запрашивает сотрудника из БД и
  сохраняет в currentEmployee для корректного заполнения ComboBox в форме
  редактирования (текущий сотрудник всегда первый в списке).

Создание нового задания (секция «Назначить задание»):
  assignTaskComboBox1 — выбор роли сотрудника.
    При смене роли: запрашиваются все сотрудники из БД, фильтруются по роли,
    ФИО загружаются в assignTaskComboBox2.
  assignTaskComboBox2 — выбор конкретного сотрудника по ФИО.
  assignTaskTextBox1 — текст задания (обязательное поле).
  assignTaskCalendarDatePicker2 — дата сдачи (по умолчанию +7 дней от сегодня).
  checkBox1 — «Прикрепить выделенные метки»:
    При отключении с пустым SelectedMarkers._points автоматически снимается.
    При включении при сохранении: в AttachedMarkers записываются Tag всех
    точек из SelectedMarkers._points плюс маркера почтового отделения через запятую.
  Кнопка «Создать»: INSERT в таблицу Задания, добавление строки в таблицу через
    DataTables.AddTaskRow(), регистрация Id в _locallyAddedTaskIds (защита от
    двойной загрузки LazyLoader).

Редактирование существующего задания (секция «Редактировать задание»):
  Поля заполняются при клике на строку таблицы.
  editTaskComboBox1 — роль: при смене загружает список сотрудников с этой ролью,
    текущий сотрудник всегда стоит первым.
  editTaskComboBox2 — ФИО нового сотрудника.
  checkBox2 — «Обновить прикреплённые метки»: если включён и есть выделение —
    AttachedMarkers обновляется из SelectedMarkers._points. Иначе — оставляется
    из _selectedTask.
  Кнопка «Сохранить»: Upsert задания, обновление строки в таблице.
  Кнопка «Удалить»: диалог подтверждения → Delete, удаление строки из таблицы.

Панель: Сотрудники
------------------
Таблица registrationDataGridView инициализируется через
DataTables.InitializeEmployeesTable(). Ленивая загрузка всех сотрудников.
Поиск по видимым столбцам кроме «Логин» (который из связанной таблицы
и не поддерживается через SearchFilter).

Регистрация нового сотрудника (секция «Регистрация»):
  Поля: Фамилия, Имя, Отчество (опционально), Роль (ComboBox из UserData._allRoles),
    Email (логин), Пароль.
  Генерация пароля: кнопка генерирует 8 случайных цифр через Random.Next(1,10).
  Генерация логина: кнопка берёт первые 3 символа Фамилии + полное Имя,
    транслитерирует через RussianTransliterator.GetTransliteration() (библиотека
    RussianTransliteration). Результат вставляется в поле Email.
  Пробелы во всех полях ввода заблокированы через KeyPress-обработчик.
  Кнопка «Зарегистрировать»: вызывает UserData.Register() — хэширует пароль
    PBKDF2-SHA256, INSERT в Логин и Сотрудники, добавление строки в таблицу,
    регистрация Id в _locallyAddedEmployeesIds.

Редактирование сотрудника (секция «Редактировать»):
  Поля заполняются при клике на строку таблицы.
  Заполнение ФИО: ФИО разбирается на части посимвольным обходом с подсчётом пробелов,
    части записываются в три отдельных поля.
  Пароль: если поле пустое — пароль не меняется (без пересчёта хэша).
    Если заполнено — HashPassword() пересчитывает хэш.
  Кнопка «Сохранить»: Update обеих таблиц (Сотрудники и Логин), обновление
    ячеек строки в таблице (FIO, Role, Login).
  Кнопка «Удалить»: диалог подтверждения → Delete из Сотрудники и Логин
    (каскад в БД удалит Задания), очистка полей, сброс _selectedEmployee.

Клик по строке сотрудников:
  Загружает Employees и Login из БД по id из скрытых ячеек.
  Сохраняет в UserData._selectedEmployee и UserData._selectedLogin.
  Сохраняет оригинальный email в UserData._originalLogin.

Кнопка проверки целостности:
  cuiPanel1_Click → открывает IntegrityCheckForm.
