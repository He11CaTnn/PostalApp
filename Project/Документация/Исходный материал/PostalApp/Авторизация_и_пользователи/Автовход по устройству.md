АВТОВХОД ПО ID МАТЕРИНСКОЙ ПЛАТЫ
=================================

Назначение
----------
Позволяет пользователю входить в приложение без ввода email и пароля на устройствах,
которым был предоставлен постоянный доступ (PermanentAccess = true в таблице Устройства).

Получение ID материнской платы
--------------------------------
Класс: SecureConfig, метод GetMotherboardId()

Используется WMI-запрос "SELECT SerialNumber FROM Win32_BaseBoard" через ManagementObjectSearcher.
Из результата берётся значение поля SerialNumber.
Если значение пустое, равно "To be filled by O.E.M." или "Default string" — возвращается null.
При любой исключительной ситуации возвращается null.
Если GetMotherboardId() вернул null или пустую строку — автовход не предпринимается,
форма сразу показывает панель ручного входа.

Последовательность автовхода
-------------------------------
1. StartupForm.RunStartupSequence() после проверки версии вызывает GetMotherboardId().
2. Если ID получен — вызывается HandleDeviceAutoLogin(motherboardId).
3. SecureConfig.FetchConfigByMotherboardId() отправляет POST /api/checkdevice
   с motherboard_id, version и exe_md5.
   - Сервер проверяет rate limit ручного входа → version → integrity → наличие записи
     в таблице Устройства с Постоянный доступ = true.
   - При успехе возвращает строку подключения к БД и координаты.
   - При отсутствии устройства возвращает HTTP 401 → метод возвращает null.
4. Если cfg == null — показывается форма ручного входа без сообщения об ошибке.
5. Если cfg получен — подключение к PostgreSQL через DataBase.TryConnectAsync().
6. UserData.LoadUserByMotherboardId() запрашивает запись из таблицы Устройства
   по motherboard_id с PermanentAccess = true, затем по цепочке загружает
   сотрудника и его логин.
7. UserData.UpdateDeviceInfo() обновляет IP, имя устройства, местоположение
   и время последнего входа без изменения PermanentAccess.
8. Выполняется Step2_CheckUpdates() и, если всё в порядке, открывается форма роли.

Регистрация и обновление устройства при ручном входе
------------------------------------------------------
Метод: UserData.RegisterOrUpdateDevice(motherboardId, permanentAccess)

Вызывается при каждом успешном ручном входе, независимо от состояния чекбокса
«Запомнить устройство». Значение permanentAccess берётся из чекбокса (_chkRemember.Checked).

Логика:
- Поиск существующей записи в таблице Устройства по motherboard_id.
- Если запись не найдена → INSERT новой с новым Guid, IdEmployee, Ip, IdMotherboard,
  NameDevaice (hostname), Location, PermanentAccess, LastEntry.
- Если запись найдена → UPDATE полей IdEmployee, Ip, NameDevaice, Location,
  PermanentAccess, LastEntry.
- PermanentAccess обновляется при каждом ручном входе: если пользователь снял
  галочку — PermanentAccess станет false и автовход при следующем запуске не сработает.

Внешний IP и местоположение
-----------------------------
Метод GetExternalIpInfoAsync() обращается к http://ip-api.com/json (без SSL).
Из ответа берётся поле query (внешний IP), city и country.
Таймаут: 5 секунд. При любой ошибке возвращается ("unknown", "").

LastEntry записывается в UTC с точностью до секунды (миллисекунды отбрасываются)
через метод TruncateToSeconds().

Проверка регистрации устройства
---------------------------------
Метод IsDeviceRegistered() проверяет наличие записи по motherboard_id независимо
от PermanentAccess. Используется для диагностики, не участвует напрямую в основном
потоке входа.
