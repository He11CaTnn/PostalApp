ПОСТРОЕНИЕ МАРШРУТА
===================

Класс: Route (статический)
Файл: Route.cs

Назначение
----------
Построение оптимального маршрута по выделенным маркерам, отрисовка линий маршрута
на карте, расчёт расстояния и времени.

Параметры расчёта времени
--------------------------
metreSeconds   = 2.0 — секунд на метр пути (темп ходьбы).
visitingSeconds = 30.0 — секунд на посещение одной точки (вручение).
Общее время: (расстояние × metreSeconds + количество_меток × visitingSeconds) / 60,
округлённое вверх (Math.Ceiling) в минутах.

Алгоритм построения (BuildRoute)
----------------------------------
1. Очищается _routesOverlay.
2. Из списка GMapMarker извлекаются координаты (Position) в List<PointLatLng>.
3. В зависимости от количества точек:
   - 1 точка: ничего не строится.
   - 2 точки: прямой маршрут между ними через DrawRouteBetweenPoints.
   - 3+ точки: оптимизация через 2-opt, затем отрисовка каждого сегмента.
4. Расчёт времени и запись в estimatedTimeMinutes.

Оптимизация маршрута (2-opt)
------------------------------
Метод: FindRouteWith2Opt(points)

Классический алгоритм 2-opt для решения задачи коммивояжёра:
  - Инициализируется маршрутом в исходном порядке.
  - В двойном цикле по всем парам рёбер (i, j):
    Проверяется: уменьшится ли длина если переставить сегмент [i+1..j] в обратном порядке.
    distance(i, i+1) + distance(j, j+1)  vs  distance(i, j) + distance(i+1, j+1)
    Если новый вариант короче — выполняется ReverseSegment(route, i+1, j).
  - Итерации продолжаются пока есть улучшения или не достигнут maxIterations = 1000.
  - Возвращает оптимизированный список точек.

Алгоритм работает на эвклидовых расстояниях (GetDistance), а не на реальных дорогах.
Физические маршруты по дорогам строятся в DrawRouteBetweenPoints через OSM Routing.

Отрисовка маршрута (DrawRouteBetweenPoints)
---------------------------------------------
Метод: DrawRouteBetweenPoints(map, start, end)

Вызывает OpenStreetMapProvider.Instance.GetRoute(start, end, ...) —
запрос реального маршрута по дорогам к API OpenStreetMap Routing.
Создаёт GMapRoute с Stroke = lineRoute (красная линия, 3px) и добавляет в _routesOverlay.
При ошибке запроса (нет соединения, API недоступен) — логирует ошибку.

Расчёт расстояния
-----------------
GetDistance() использует OpenStreetMapProvider.Instance.Projection.GetDistance() —
геодезическое расстояние в метрах между двумя точками на земной поверхности.

CalculateRouteDistance() суммирует GetDistance для всех последовательных пар точек.

Форматирование времени (FormatTime)
-------------------------------------
  < 60 мин      → "N мин"
  60+ мин, 0 мин остатка → "N ч"
  иначе         → "N ч M мин"
