ХЕШИРОВАНИЕ ПАРОЛЕЙ
====================

Класс: PasswordHasher (статический)
Файл: PasswordHasher.cs
Библиотека: Microsoft.AspNetCore.Cryptography.KeyDerivation

Алгоритм хеширования паролей
------------------------------
Алгоритм: PBKDF2-HMAC-SHA256
Параметры:
  Размер соли:      128 бит (16 байт)
  Размер хэша:      256 бит (32 байта)
  Число итераций:   100 000

HashPassword(password) → string (Base64):
  1. Генерируется криптографически случайная соль (RandomNumberGenerator.Create(), GetBytes(16)).
  2. Вычисляется PBKDF2 хэш: KeyDerivation.Pbkdf2(password, salt, HMACSHA256, 100000, 32).
  3. Соль и хэш конкатенируются: byte[16 + 32 = 48].
  4. Результат кодируется в Base64 — именно эта строка хранится в БД в столбце «Пароль».

VerifyPassword(password, storedHash) → bool:
  1. Base64-декодируется storedHash в byte[48].
  2. Первые 16 байт — соль.
  3. Следующие 32 байта — сохранённый хэш.
  4. Вычисляется PBKDF2 с тем же паролем, той же солью, теми же параметрами.
  5. Побайтовое сравнение: ByteArraysEqual() проверяет каждый байт через &=,
     не прерываясь при первом несовпадении (защита от timing-атак).

Совместимость с сервером
-------------------------
Сервер (Python, main.py) использует verify_pbkdf2():
  - hashlib.pbkdf2_hmac('sha256', password.encode('utf-8'), salt, 100000, dklen=32)
  - Соль и хэш объединяются и кодируются в Base64.
Параметры идентичны клиентской реализации, поэтому хэши взаимозаменяемы.

Хеширование устройств
----------------------
HashDevice(deviceId) → string (Base64):
  SHA-256 от UTF-8 байт deviceId без соли. Используется для хранения ID устройств
  в хэшированном виде при необходимости. В текущей архитектуре ID материнской платы
  хранится в БД в открытом виде; HashDevice/VerifyDevice — вспомогательные методы.

GetHashInfo(storedHash):
  Отладочный метод: декодирует Base64 и возвращает размеры компонентов в битах и байтах.
