ВЫДЕЛЕНИЕ МАРКЕРОВ
==================

Класс: SelectedMarkers (статический)
Файл: SelectedMarkers.cs

Назначение
----------
Управление состоянием выделенных маркеров для построения маршрута.
Хранит список выбранных пользователем точек и обеспечивает визуальное
переключение иконки между обычным и выделенным состоянием.

Состояние
---------
_points         — List<GMapMarker> всех выделенных маркеров.
_selectionMode  — bool, true когда хотя бы один маркер выделен.

Выделение маркера (SelectMarker)
----------------------------------
Метод: SelectMarker(marker, countSelected)

1. Из Tag маркера извлекается Guid.
2. Загружается запись из таблицы Метки по этому Guid.
3. Если маркер находится в _homesOverlay — он удаляется оттуда.
4. Marker.AddMarkerToMap(response, isSelected: true) — создаёт новый маркер
   с выделенной иконкой и добавляет в _homesOverlay и в _points.
5. Кнопка countSelected обновляет свой текст количеством выделенных маркеров.

Снятие выделения (RemoveMarkerSelection)
------------------------------------------
Метод: RemoveMarkerSelection(marker, countSelected, oldMarkersCount)

1. Загружается запись маркера из БД.
2. Маркер с выделенной иконкой удаляется из _homesOverlay.
3. Marker.AddMarkerToMap(response, isSelected: false) — возвращает обычную иконку.
4. Маркер удаляется из _points.
5. Счётчик обновляется.
6. Если _points пуст:
   - _selectionMode = false.
   - countSelected возвращает исходное значение (oldMarkersCount) или "----".

Снятие всего выделения (ClearAllSelection)
--------------------------------------------
Метод: ClearAllSelection(map, countSelected, timeRoute, oldMarkersCount)

Поочерёдно вызывает RemoveMarkerSelection для каждого маркера из _points.ToArray()
(копия списка, т.к. список модифицируется в процессе).
После очистки:
  - Обновляет timeRoute кнопку текстом расчётного времени (Route.FormatTime).
  - _points.Clear() и _selectionMode = false.
  - gMap.Refresh().
