МАРКЕРЫ
========

Класс: Marker (статический)
Файл: Marker.cs

Назначение
----------
Создание, настройка и добавление визуальных маркеров GMap.NET на карту.
Маркер представляет одну запись из таблицы Метки.

Типы зданий
-----------
_typeBuildings — список допустимых типов: «Частный дом», «Многоквартирный дом», «Здание организаций».
Тип «Post Office» — обозначение почтового отделения (обрабатывается отдельно).

Добавление маркера на карту (AddMarkerToMap)
---------------------------------------------
Метод: AddMarkerToMap(markerData, isSelected = false)

1. Создаётся PointLatLng из Latitude и Longitude.
2. Выбор иконки (Bitmap из Properties.Resources):
   Обычный маркер (isSelected = false):
     "частный дом" / "не указан" / пустой → Resources.Частный_дом
     "post office"                         → Resources.почта
     "многоквартирный дом"                 → Resources.многоэтажный_дом
     всё остальное                         → Resources.Здание_организаций
   Выделенный маркер (isSelected = true):
     всегда → Resources.маркер (специальная иконка выделения)

3. Масштабирование: scale = 0.2 (20% от оригинала). Bitmap пересоздаётся в новом размере.

4. Создаётся GMarkerGoogle. Смещение (Offset) устанавливается как (-width/2, -height)
   — «подошва» иконки указывает на точку координат.

5. Тег маркера (Tag) = markerData.Id (Guid) — используется для идентификации при кликах.

6. SearchCountSubscriptionsInMarker() — подсчёт активных подписок:
   - Парсит строку markerData.IdReaders (Guid через запятую) вручную символ за символом.
   - Выполняет один запрос к таблице Подписки с фильтром id IN (список Guid).
   - Возвращает количество найденных записей.

7. TooltipMarker() — настройка всплывающей подсказки (OnMouseOver):
   Строки: «Улица», «Дом», «Тип строения», «Активные подписки».
   Фон: белый, текст: чёрный, отступ 10px.

8. Маркер добавляется в соответствующий оверлей:
   "post office" → _postOfficeOverlay
   всё остальное → _homesOverlay
   Если isSelected = true — маркер также добавляется в SelectedMarkers._points.

Маркеры границ участков (CreateMarkerBorderRegion)
---------------------------------------------------
Метод: CreateMarkerBorderRegion(gMap, point, node)

Создаёт GMarkerGoogle с иконкой GMarkerGoogleType.blue_small.
Tag = node.Id (Guid узла из таблицы Узлы).
Добавляется в _boundsOverlay.
Используется при редактировании границ участков (LoadBorders).
