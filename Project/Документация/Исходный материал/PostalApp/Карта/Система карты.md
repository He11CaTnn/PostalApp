СИСТЕМА КАРТЫ
=============

Класс: Map (статический)
Файл: Map.cs
Библиотека: GMap.NET (GMap.NET.Core.dll, GMap.NET.WindowsForms.dll)

Назначение
----------
Управление картографическим компонентом GMapControl: инициализация, загрузка данных
из БД, управление видимостью слоёв, автомасштабирование.

Провайдеры карт
---------------
sputnikProvider = GMapProviders.GoogleSatelliteMap — спутниковый режим.
streetProvider  = GMapProviders.OpenCycleMap       — уличный режим (по умолчанию).

Параметры зума
--------------
minZoomLevel = 9, maxZoomLevel = 18.
Начальный зум: среднее между min и max.
autoModMap[0] = 14, autoModMap[1] = 16 — пороги автоматического режима.

Слои (Overlays)
---------------
Карта использует пять именованных GMapOverlay:
  _homesOverlay     ("markers")  — все жилые и коммерческие метки
  _postOfficeOverlay ("pochta")  — метки почтовых отделений
  _regionsOverlay   ("regions")  — закрашенные полигоны участков
  _boundsOverlay    ("bounds")   — границы участков и редактируемые узлы
  _routesOverlay    ("routes")   — линии маршрута

InitializeMap(GMapControl):
  Устанавливает все параметры GMapControl, создаёт оверлеи и добавляет их
  в gMap.Overlays. Начальная позиция определяется через SetStartPoisitionMap().

SetStartPoisitionMap(GMapControl):
  Запрашивает из таблицы Метки запись с TypeBuilding == "Почта" (SINGLE).
  Если найдена — устанавливает startPosition. Иначе — используется Москва (55.7522, 37.6156).
  Координаты также могут быть переопределены из конфига сервера (Map.startPosition
  устанавливается в ApplyConfigToProgram).

Загрузка маркеров (LoadMarkers)
---------------------------------
  Директор: загружаются все метки без фильтрации (From<Markers>().Get()).
  Прочие роли: метки фильтруются по IdRegion IN (CurrentUser.RegionIds).
  Результат сохраняется в _userMarkers.
  DisplayInterfaceOnMap() последовательно вызывает Marker.AddMarkerToMap() для каждой метки.

Загрузка регионов (LoadRegions)
---------------------------------
  Директор: все регионы.
  Прочие: регионы только из CurrentUser.RegionIds.
  Для каждого региона:
    1. Загружаются узлы из таблицы Узлы, отсортированные по Номер.
    2. Если узлов менее 3 — полигон не создаётся.
    3. Цвет: парсится из Region.Color (поддерживает "#RRGGBB" и "RRGGBB").
       При ошибке — Color.Gray.
    4. Создаётся GMapPolygon в _regionsOverlay (полупрозрачная заливка, IsHitTestVisible = false).
    5. Для каждой пары соседних узлов создаётся линия границы в _boundsOverlay.

Загрузка границ для редактирования (LoadBorders)
-------------------------------------------------
  Загружает все регионы и узлы без учёта роли пользователя.
  Полигоны в _regionsOverlay создаются с IsHitTestVisible = true и Tag = region.Id
  — для кликабельности при редактировании.
  Узлы отображаются как отдельные маркеры через Marker.CreateMarkerBorderRegion().
  Используется в формах редактирования участков.

Обновление карты (RefreshMap)
-------------------------------
  Очищает overlays homesOverlay, postOfficeOverlay, regionsOverlay, boundsOverlay.
  Затем последовательно вызывает LoadMarkers и LoadRegions.

Автоматический режим (ApplyAutoZoomSettings)
---------------------------------------------
  При активном автоматическом режиме (isAutoModeActive = true):
    zoom >= 14:            виден _boundsOverlay и _homesOverlay, скрыт _regionsOverlay.
    zoom >= 14 и < 16:     всё видно (по коду — та же ветка что zoom >= 14, ошибка логики).
    zoom < 14:             виден _regionsOverlay и _boundsOverlay, скрыт _homesOverlay.
  Вызывается при событии изменения зума.
