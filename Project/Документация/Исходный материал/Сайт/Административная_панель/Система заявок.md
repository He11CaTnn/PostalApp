СИСТЕМА ЗАЯВОК НА ДОСТУП
=========================

Файл: js/app.js (пользователь), js/admin.js (администратор)

Пользовательская сторона
--------------------------
Блок отображается пользователям без роли (не admin, не moderator).
Логика updateExtraDownloadCard() определяет что показывать:

  Не авторизован:
    Текст «Войдите через Google, чтобы подать заявку».

  requestStatus == null (заявки нет):
    Текст «Нажмите кнопку ниже» + кнопка «📨 Подать заявку на доступ».

  requestStatus == "pending":
    Золотой блок «⏳ Заявка отправлена. Ожидайте решения администратора.»
    Кнопка скрыта, повторная подача невозможна.

  requestStatus == "rejected":
    Красный блок «❌ Заявка отклонена. Обратитесь к администратору напрямую.»

Отправка заявки (handleSendRequest)
-------------------------------------
Вызывается кнопкой «📨 Подать заявку».
1. Кнопка блокируется (disabled, текст «Отправка...»).
2. db.collection('users').doc(currentUser.uid).set({
     requestStatus: 'pending',
     requestedAt: serverTimestamp()
   }, { merge: true })
3. Локально: userData.requestStatus = 'pending'.
4. Обновляются updateExtraDownloadCard() и updateAuthSection() — без перезагрузки страницы.

Административная сторона (admin.js)
------------------------------------
Панель заявок загружает всех пользователей с requestStatus == 'pending':
  db.collection('users').where('requestStatus','==','pending').get()
Список сортируется по requestedAt (убывание) — новейшие заявки сверху.
orderBy не используется намеренно — во избежание необходимости составного индекса Firestore.

Счётчик pending-badge в шапке панели и stat-pending в статистике обновляются при каждой загрузке.

Одобрение модератором (approveRequest):
  db.collection('users').doc(uid).update({ requestStatus:'approved', isModerator:true })
  Пользователь получает isModerator = true — доступ к скачиванию Extra.

Одобрение администратором (approveAsAdmin):
  Только для суперадмина (isSuperAdminSession == true).
  Проверяется, что email цели != superAdminEmail (нельзя "назначить" суперадмина).
  db.collection('users').doc(uid).update({ requestStatus:'approved', isAdmin:true, isModerator:true })

Отклонение (rejectRequest):
  db.collection('users').doc(uid).update({ requestStatus:'rejected' })
  isAdmin и isModerator не затрагиваются.

После любого действия:
  removeReqRow(uid) — удаляет строку из allRequests, перерисовывает таблицу,
  обновляет бейдж. loadStats() обновляет счётчики статистики.

Поиск по заявкам (filterRequests)
-----------------------------------
Фильтрует локальный кеш allRequests по подстроке в name или email.
Поиск регистронезависимый, выполняется без запросов к Firestore.
