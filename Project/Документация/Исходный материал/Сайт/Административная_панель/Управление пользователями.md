АДМИНИСТРАТИВНАЯ ПАНЕЛЬ — УПРАВЛЕНИЕ ПОЛЬЗОВАТЕЛЯМИ
=====================================================

Файл: js/admin.js
Страница: admin.html

Доступ к панели
----------------
При загрузке admin.html: onAdminAuthChanged(user) проверяет авторизацию.

Если user == null → показывается форма входа (#access-gate).
Если user != null:
  Проверяется email == superAdminEmail → isSuperAdminSession = true.
  Иначе: db.collection('users').doc(uid).get() → isAdmin == true.
  Если ни то ни другое → auth.signOut() + сообщение об ошибке.
  Если проверка прошла → showAdminPanel(), loadAllData().

Глобальные переменные admin.js
-------------------------------
db, auth                 — ссылки Firebase
adminUser                — объект текущего авторизованного администратора
isSuperAdminSession      — true если это суперадмин
allUsers                 — кеш всех пользователей (для фильтрации без запросов к Firestore)
allRequests              — кеш заявок в ожидании

Загрузка данных (loadAllData)
------------------------------
Promise.all([loadRequests(), loadUsers()]) — параллельно.

loadRequests() — только «pending»-заявки (описано в файле «Система заявок»).

loadUsers():
  db.collection('users').get() — все документы коллекции.
  Кешируется в allUsers.
  Сортировка по registeredAt (убывание) — новые пользователи сверху.
  Вызывает loadStats() и renderUsers().

Отображение пользователей (renderUsers)
-----------------------------------------
Для каждого пользователя определяется currentRole:
  superadmin — email == superAdminEmail
  admin      — isAdmin == true
  moderator  — isModerator == true
  user       — всё остальное

Столбец роли (roleCol) зависит от комбинации:

  Суперадмин (isSA):
    Текст «👑 Главный администратор», без возможности изменения.

  Сам администратор (isSelf = adminUser.uid == u.id):
    Текст текущей роли + «(вы)», без возможности изменения.

  Другой пользователь, суперадмин просматривает (isSuperAdminSession):
    select с вариантами: Пользователь / Модератор / Администратор.

  Другой пользователь — администратор (не superadmin):
    Если цель — admin → текст «Администратор» без select.
    Иначе → select с вариантами: Пользователь / Модератор (без Администратора).

Смена роли (setRole)
---------------------
Защиты:
  1. Нельзя менять свою роль (adminUser.uid === uid) → reload.
  2. Нельзя назначать admin если !isSuperAdminSession → ошибка.
  3. Нельзя трогать суперадмина (email == superAdminEmail) → ошибка.

При успехе:
  update = { isAdmin: newRole==='admin', isModerator: newRole==='admin'||newRole==='moderator' }
  db.collection('users').doc(uid).update(update)
  loadStats() — обновление счётчиков.

Поиск пользователей (filterUsers)
-----------------------------------
Фильтрует allUsers по подстроке в name или email (без Firestore-запросов).
renderUsers() перерисовывает таблицу с отфильтрованным списком.

Статистика (loadStats)
-----------------------
Подсчитывает из списка users:
  stat-total  — общее количество
  stat-admins — isAdmin == true ИЛИ email == superAdminEmail
  stat-mods   — isModerator == true И !isAdmin И email != superAdminEmail
  stat-pending — requestStatus == 'pending'
Обновляет соответствующие элементы через setEl(id, value).

Табы панели (switchTab)
-------------------------
Переключает активный таб между «Заявки» (tab-requests) и «Пользователи» (tab-users).
Скрывает/показывает .admin-panel через класс active.
Снимает/ставит класс active на кнопках .admin-tab.
