КАРУСЕЛЬ СКРИНШОТОВ И ЛАЙТБОКС
================================

Файл: js/app.js

COVERFLOW КАРУСЕЛЬ (renderScreenshots, cfUpdate)
-------------------------------------------------
Отображает скриншоты из SITE_CONFIG.screenshots в формате «CoverFlow» —
центральный слайд крупный и яркий, боковые уменьшены, повёрнуты и затемнены.

Если screenshots пуст — секция скрывается (display:none).

renderScreenshots():
  Создаёт HTML-элементы .cf-slide для каждого скриншота.
  На каждый слайд вешаются: клик → cfHandleClick(idx).
  Свайп тач: touchstart/touchend — dx > 40px → carouselMove(±1).
  Свайп мышью: mousedown/mousemove/mouseup с тем же порогом.
  Точки навигации (carousel-dots) создаются в визуальном порядке
  (не в порядке индексов массива).

Алгоритм позиционирования (cfUpdate):
  Для каждого слайда вычисляется raw = (i - carouselIndex + total) % total
  (расстояние по кругу от активного слайда).

  raw → offset:
    0 → 0 (центр)
    нечётные: offset = (raw+1)/2 (правая сторона)
    чётные ненулевые: offset = -(raw/2) (левая сторона)

  Из offset:
    translateX = offset * 30%
    scale = max(0.52, 1 - abs(offset) * 0.15)
    rotateY = offset > 0 ? -28° : offset < 0 ? 28° : 0
    zIndex = total - abs(offset)
    opacity = abs > 2 ? 0 : max(0.28, 1 - abs * 0.3)
    brightness = abs > 0 ? max(0.42, 1 - abs * 0.24) : 1
    pointerEvents = abs > 2 ? 'none' : 'auto'

cfHandleClick(idx):
  Если idx == carouselIndex → открывает лайтбокс (openLightbox).
  Иначе → carouselGoTo(idx).

carouselGoTo(idx): зациклено ((idx % total + total) % total).
carouselMove(dir): carouselGoTo(carouselIndex + dir).
Кнопки Prev/Next никогда не блокируются — карусель бесконечная.

ЛАЙТБОКС (openLightbox, initLightboxEvents)
--------------------------------------------
Полноэкранный просмотрщик скриншотов с зумом и перетаскиванием.

Состояние: lbIndex, lbZoom, lbPanX, lbPanY, lbDragging, lbDragStart.

Открытие (openLightbox):
  lbZoom = 1, lbPanX = 0, lbPanY = 0.
  Устанавливает img.src и caption.
  Применяет transform через applyLbTransform().
  Убирает class 'hidden' у #lightbox.
  document.body.style.overflow = 'hidden' (блокировка прокрутки).

applyLbTransform():
  #lightbox-img-wrap → transform: translate({panX}px, {panY}px) scale({zoom})
  Синхронизирует слайдер зума (#lightbox-zoom-slider).

Навигация по стрелкам (lightboxNav(dir)):
  Зациклена. Сбрасывает zoom и pan при переходе.

Зум колёсиком мыши:
  Реализован без CSS-класса. Вычисляется позиция курсора относительно центра viewport.
  factor = deltaY < 0 ? 1.12 : 0.88 (зум/разум).
  Зум привязывается к положению курсора: pan корректируется для сохранения точки под курсором.
  Диапазон: 0.5x — 5x.

Перетаскивание (drag):
  mousedown → lbDragging = true, фиксируется lbDragStart.
  mousemove → lbPanX/Y = clamp(eventX - startX, -limit, +limit).
  Граница: (SITE_CONFIG.lightboxPanLimit || 600) * lbZoom.
  mouseup → lbDragging = false.

Закрытие:
  Кнопка × или клик по фону (#lightbox или #lightbox-content при !lbDragging).
  Клавиша Escape (обработчик на document).
  body.style.overflow = '' — восстанавливается прокрутка.

setZoomFromSlider(val):
  Устанавливает lbZoom из слайдера, сбрасывает pan.

Клавиши:
  Escape → closeLightboxBtn()
  ArrowLeft → lightboxNav(-1)
  ArrowRight → lightboxNav(1)
