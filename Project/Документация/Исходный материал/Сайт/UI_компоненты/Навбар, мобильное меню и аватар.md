НАВБАР, МОБИЛЬНОЕ МЕНЮ, АВАТАР
================================

Файл: js/app.js

НАВБАР (initNavScroll, updateNavAuth)
--------------------------------------
initNavScroll():
  Подписывается на scroll-событие.
  При scrollY > 20 → navbar.classList.add('scrolled').
  Класс 'scrolled' используется CSS для визуального изменения фона.

updateNavAuth(user):
  Вызывается из onAuthStateChanged.
  Управляет видимостью элементов навбара в зависимости от авторизации:

  Не авторизован:
    #nav-login-btn — видим
    #nav-user-widget — скрыт
    #nav-admin-link — скрыт
    #mobile-login-btn — виден, #mobile-logout-btn — скрыт

  Авторизован:
    #nav-login-btn — скрыт
    #nav-user-widget — виден (display: flex)
    Аватар: если user.photoURL — показывается <img>, иначе — placeholder с инициалами.
    #nav-user-name — первое слово displayName или email.
    #nav-dd-name, #nav-dd-email — полное имя и email в dropdown.
    #nav-admin-link, #mobile-admin-link — видны только при isAdminRole().

МОБИЛЬНОЕ МЕНЮ (initMobileMenu)
---------------------------------
Бургер (#nav-burger) открывает/закрывает #mobile-menu-drawer.
При открытии: drawer.classList.add('open'), overlay.classList.add('visible').
Закрытие:
  Повторный клик по бургеру.
  Клик по оверлею (#mobile-menu-overlay).
  Клик по любой ссылке внутри drawer.
closeMobileMenu() снимает классы 'active', 'open', 'visible'.

DROPDOWN АВАТАРА (initAvatarDropdown)
---------------------------------------
#nav-avatar-trigger — кнопка-аватар в навбаре.
Клик по trigger → #nav-avatar-dropdown.classList.toggle('open').
Клик в любое другое место документа → dropdown.classList.remove('open').
e.stopPropagation() на trigger предотвращает немедленное закрытие при открытии.

ЛИЧНЫЙ КАБИНЕТ (updateAuthSection)
-------------------------------------
Управляет блоком #auth на главной странице.

Не авторизован:
  #login-card — виден (кнопка входа через Google).
  #user-card — скрыт.

Авторизован:
  #login-card — скрыт.
  #user-card — виден.
  Аватар, displayName, email заполняются из объекта user.
  #user-role-badge — текст и стиль по роли:
    Суперадмин → золотой бейдж «Главный администратор».
    Администратор → золотой бейдж «Администратор».
    Модератор → синий бейдж «Модератор».
    Пользователь → серый бейдж «Пользователь».
  #status-block — текстовый блок с описанием статуса:
    Суперадмин/Администратор → «Полный доступ» / «Панель управления».
    Модератор → «Доступно дополнительное приложение».
    Пользователь: текст зависит от requestStatus (null / pending / rejected).

TOAST-УВЕДОМЛЕНИЯ (showToast)
-------------------------------
showToast(msg, type='info', dur=3500)
Добавляет <div class="toast toast-{type}"> в #toast-container.
type: 'success' (✅), 'error' (❌), 'info' (ℹ️).
Через dur миллисекунд запускается обратная CSS-анимация и элемент удаляется.
Работает в обоих файлах (app.js и admin.js) — реализована независимо в каждом.

REVEAL-АНИМАЦИИ (initRevealAnimations)
----------------------------------------
IntersectionObserver следит за элементами с классом .reveal.
При пересечении с viewport (threshold 0.12) добавляется класс .visible.
transitionDelay = (i % 4) * 0.08s — лёгкий каскадный эффект для групп элементов.

applyConfig()
--------------
Вызывается первой при DOMContentLoaded.
Вставляет строки из SITE_CONFIG в DOM по ID элементов:
  nav-app-name, hero-app-name-ru, hero-app-name-en, hero-subtitle,
  dl-main-title, dl-extra-title, footer-app-name, footer-copy, mockup-title.
Устанавливает favicon из SITE_CONFIG.icons.mainApp.
Telegram-кнопка в футере показывается только если SITE_CONFIG.contact.telegram не пустой.
