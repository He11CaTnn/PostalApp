ВОЛНОВАЯ СЕТКА И БЕГУЩАЯ СТРОКА
=================================

Файл: js/app.js

ВОЛНОВАЯ СЕТКА (initWaveGrid)
------------------------------
Canvas-анимация в фоне hero-секции. Рисует анимированную сетку из горизонтальных
и вертикальных волнообразных линий.

Включение: SITE_CONFIG.waveGrid.enabled == true.
Canvas: #wave-grid-canvas, позиционирован абсолютно внутри #home (hero).

Размер canvas подстраивается под размеры #home (resize-listener).

Цикл отрисовки (draw):
  Параметр t (время) увеличивается на 0.016 при каждом кадре (≈ 60fps).

  Горизонтальные линии (волны по вертикали):
    Для каждой строки с шагом cellSize:
      yBase = row * cellSize
      dy = hAmplitude * sin(x * hFrequency * 0.01 + t * hSpeed)
      Линия рисуется по точкам с шагом 3px по X.

  Вертикальные линии (волны по горизонтали):
    Для каждой колонки с шагом cellSize:
      xBase = col * cellSize
      dx = vAmplitude * sin(y * vFrequency * 0.01 + t * vSpeed)
      Линия рисуется по точкам с шагом 3px по Y.

  ctx.globalAlpha = opacity — прозрачность всего слоя.
  Цикл запускается через requestAnimationFrame.

При disabled (enabled == false) canvas остаётся невидимым и не рисуется.

БЕГУЩАЯ СТРОКА (initTicker)
-----------------------------
Две горизонтальные бегущие строки с технологическими тегами приложения.
CSS-анимация (transform: translateX) — без JS-скролла.

Список элементов (items) жёстко задан в initTicker() и содержит 13 пунктов:
  «Оптимизация маршрутов алгоритмом 2-opt»,
  «Интерактивная карта с OpenStreetMap»,
  «Управление подписками и читателями», и т.д.

buildTrack(trackEl, list):
  Дублирует список (doubled = [...list, ...list]) для создания бесшовного цикла.
  Каждый элемент оборачивается в <span class="ticker-item"> с <span class="ticker-dot">.

Строка 1 (#ticker-track-1): список в прямом порядке.
Строка 2 (#ticker-track-2): список в обратном порядке (reverse) — движется в другую сторону.
Скорость: SITE_CONFIG.tickerSpeed.row1/row2 секунд на полный цикл анимации.
