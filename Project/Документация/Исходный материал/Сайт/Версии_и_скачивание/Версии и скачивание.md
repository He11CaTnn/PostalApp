ВЕРСИИ И СКАЧИВАНИЕ ПРИЛОЖЕНИЙ
================================

Файл: js/app.js

Манифест версий
----------------
Формат JSON-файла manifest.json:
{
  "versions": ["0.1.22", "0.1.21"],
  ...прочие поля игнорируются сайтом...
}
Первый элемент versions[] — самая новая версия.

Основное приложение:  http://{IP_СЕРВЕРА}/updates/manifest.json
Доп. приложение:      https://postalapp.ru/assets/postalapp-extra/manifest.json

Почему основное по IP, а Extra по домену:
  Обновления PostalApp раздаются с того же Nginx-блока что и API (порт 80,
  server_name = IP). Домен не обязателен для файловой раздачи, а перенастройка
  добавит зависимость от DNS. Extra-файлы лежат прямо в папке сайта и
  отдаются через HTTPS-блок домена — это удобнее.

Загрузка версий (loadAllVersions → loadVersionsForApp)
-------------------------------------------------------
Вызывается при DOMContentLoaded параллельно для обоих приложений через Promise.all.

Для каждого type ('main' / 'extra'):
  1. fetch(manifestUrl + '?_=' + Date.now()) — запрос без кеша.
  2. Проверяется res.ok и наличие versions[].
  3. Из каждого элемента versions[] строится объект {url, version}:

  Основное:
    url = {mainVersionBase}v{v}/PostalApp_Setup_v{v}.exe
    Пример: http://{IP_СЕРВЕРА}/updates/versions/v0.1.22/PostalApp_Setup_v0.1.22.exe

  Дополнительное:
    url = {extraVersionBase}PostalApp-Extra_Setup_v{v}.exe
    Пример: https://postalapp.ru/assets/postalapp-extra/versions/PostalApp-Extra_Setup_v0.25.exe

  4. Список записывается в mainVersionsList / extraVersionsList.
     mainDlUrl / extraDlUrl устанавливается на URL первого (новейшего) элемента.
  5. populateVersionSelect() заполняет <select> опциями.
  6. Для основного: badge версии в hero-секции обновляется текстом «v{версия}».

При ошибке загрузки манифеста основного:
  select помечается ошибкой, кнопка скачивания блокируется.
Для Extra ошибка некритична.

Выпадающий список версий (populateVersionSelect)
-------------------------------------------------
select отображается только после загрузки версий.
Опции: «v{версия} (последняя)» для первого, «v{версия}» для остальных.
При смене опции: mainDlUrl / extraDlUrl обновляется на value выбранной.

Скачивание (handleMainDownload / handleExtraDownload)
------------------------------------------------------
triggerDownload(url):
  Создаётся временный <a href=url download=''>.
  Добавляется в document.body, вызывается .click(), затем удаляется.
  Браузер инициирует скачивание файла напрямую по URL.

Доступ к скачиванию Extra:
  Кнопка и select — только если isAdminRole() или isModeratorRole() = true.
  Для обычных пользователей показывается блок с информацией о заявке.
  Если extraVersionsList пуст — сообщение «файл ещё не загружен».

compareVersions(a, b):
  Разбивает строки 'x.y.z' по точке, сравнивает покомпонентно.
  Возвращает: 1 (a новее), -1 (b новее), 0 (равны).
