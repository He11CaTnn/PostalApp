FIREBASE — ИНИЦИАЛИЗАЦИЯ И АУТЕНТИФИКАЦИЯ
==========================================

Файл: js/app.js
Переменные: db (Firestore), auth (Firebase Auth), currentUser, userData

Инициализация (initFirebase)
-----------------------------
Вызывается при DOMContentLoaded.
Проверяет конфиг: если apiKey пустой или начинается с «ВАШ» — показывает toast и прекращает.
firebase.initializeApp(SITE_CONFIG.firebase) инициализирует Firebase SDK.
Создаёт db = firebase.firestore() и auth = firebase.auth().
Подписывается на auth.onAuthStateChanged(onAuthStateChanged).

Аутентификация (Google OAuth)
------------------------------
handleGoogleSignIn():
  auth.signInWithPopup(new firebase.auth.GoogleAuthProvider())
  При успехе — Firebase вызывает onAuthStateChanged с объектом user.
  При popup-closed-by-user (пользователь закрыл окно) — toast не показывается.

handleLogout():
  auth.signOut() — Firebase вызывает onAuthStateChanged с null.

Жизненный цикл авторизации (onAuthStateChanged)
-------------------------------------------------
Вызывается автоматически при каждом изменении состояния: вход, выход, перезагрузка.

При user != null:
  1. ensureUserInFirestore(user) — создаёт или обновляет запись в Firestore.
  2. loadUserData(user.uid) — читает полные данные пользователя из Firestore.
  3. updateNavAuth(user) — обновляет навбар.
  4. updateAuthSection(user) — обновляет блок личного кабинета.
  5. updateExtraDownloadCard() — обновляет карточку скачивания Extra.

При user == null:
  userData = null, обновляется UI (кнопка «Войти», скрыты виджеты пользователя).

Регистрация при первом входе (ensureUserInFirestore)
-----------------------------------------------------
Проверяет наличие документа /users/{uid} в Firestore.
Если документ не существует — создаёт:
  email, name (displayName или ''), photoURL, isModerator:false, isAdmin:false,
  requestStatus:null, registeredAt:serverTimestamp().

Если документ существует — обновляет только email, name, photoURL через merge:true.
Это обеспечивает актуальность отображаемых данных без перезаписи ролей.

Загрузка данных пользователя (loadUserData)
--------------------------------------------
GET /users/{uid} из Firestore → userData.
userData используется во всём приложении для проверки ролей (isAdmin, isModerator, requestStatus).

Глобальные переменные
---------------------
currentUser — объект Firebase User (email, displayName, photoURL, uid) или null
userData    — данные из Firestore (isAdmin, isModerator, requestStatus и т.д.) или null
db          — ссылка на Firestore
auth        — ссылка на Firebase Auth
