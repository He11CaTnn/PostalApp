СТРУКТУРА ФАЙЛОВ ПРОЕКТА
=========================

Домен сайта: https://postalapp.ru

Корень сайта
------------
index.html         — главная страница (лендинг + личный кабинет + скачивание)
admin.html         — закрытая панель администратора (доступна по /admin)
firestore.rules    — правила безопасности Cloud Firestore
qr-code.png        — QR-код (ссылка на сайт)
robots.txt         — запрет/разрешение индексации поисковиками

js/
  config.js        — единственный файл конфигурации сайта (редактируется вручную)
  app.js           — вся логика главной страницы
  admin.js         — вся логика административной панели

css/
  style.css        — единый файл стилей

assets/
  screenshot1.png                          — скриншот приложения (карта)
  screenshot2.png                          — скриншот (подписки)
  screenshot3.png                          — скриншот (задачи)

  icons/
    app-main.png                           — иконка основного приложения
    app-extra.png                          — иконка дополнительного приложения
    README.txt                             — инструкция по замене иконок

  postalapp-extra/
    manifest.json                          — манифест версий PostalApp Extra
    versions/
      PostalApp-Extra_Setup_v0.25.exe      — установщик версии 0.25

Файлы основного приложения (PostalApp)
---------------------------------------
Расположены на том же сервере, раздаются через /updates/ внутри Nginx-конфига сайта:
  /updates/manifest.json                         — глобальный манифест
  /updates/versions/v{x.y.z}/update.zip          — архив обновлений
  /updates/versions/v{x.y.z}/version_manifest.json
  /updates/versions/v{x.y.z}/PostalApp_Setup_v{x.y.z}.exe

Физически файлы хранятся в {ПАПКА_ОБНОВЛЕНИЙ} на сервере и пробрасываются через:
  location /updates/ { alias {ПАПКА_ОБНОВЛЕНИЙ}/; }

Пути в config.js → urls:
  mainManifest:    http://{IP_СЕРВЕРА}/updates/manifest.json
    (обновления PostalApp — по HTTP на прямой IP, т.к. API-сертификат отдельный)
  mainVersionBase: http://{IP_СЕРВЕРА}/updates/versions/
  extraManifest:   https://postalapp.ru/assets/postalapp-extra/manifest.json
  extraVersionBase: https://postalapp.ru/assets/postalapp-extra/versions/

Маршрутизация URL (SPA-режим)
-------------------------------
Nginx настроен в SPA-режиме: любой несуществующий путь отдаёт index.html.
JS в index.html при загрузке проверяет window.location.pathname и скроллит
к нужной секции страницы:
  /features → скролл к секции «Возможности»
  /download → скролл к секции «Скачать»
  /auth     → скролл к секции авторизации

Специальный маршрут:
  /admin → Nginx отдаёт admin.html (без изменения URL в адресной строке).

Ссылки на сайте ведут на пути (не якоря):
  href="/features", href="/download", href="/", href="/admin"
  (НЕ href="#features" и НЕ href="index.html")

Внешние зависимости (CDN)
---------------------------
Firebase SDK (app, auth, firestore) — Google CDN (gstatic.com).
Шрифт Inter — Google Fonts.
Установка npm/webpack не требуется — сайт статический.
