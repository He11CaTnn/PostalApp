КОНФИГУРАЦИЯ САЙТА (config.js)
================================

Файл: js/config.js
Объект: SITE_CONFIG (глобальный, доступен из app.js и admin.js)

Назначение
----------
Единственный файл, который необходимо редактировать для настройки сайта.
Все остальные JS-файлы читают параметры из SITE_CONFIG и не содержат жёстко
прошитых строк, относящихся к конкретному проекту.

Блок: названия приложений
--------------------------
appNameSystem      — системное название (используется в title страницы и футере)
appNameRu          — русскоязычное название (hero-секция, карточки скачивания)
appShort           — короткое название (навбар, footer)
extraAppNameRu     — название дополнительного приложения (карточка скачивания Extra)
extraAppNameSystem — системное название Extra (tooltip, заголовки)

Блок: главный администратор
-----------------------------
superAdminEmail    — email, который считается главным администратором.
Этот email проверяется:
  - в JS (isSuperAdmin): сравнивается с user.email от Firebase Auth
  - в Firestore Rules (isSuperAdmin): сравнивается с request.auth.token.email
  - в admin.js: блокирует разжалование, назначение администраторов только им
Значение жёстко фиксировано и не может быть изменено через UI.

Блок: иконки
-------------
icons.mainApp      — путь к PNG-иконке основного приложения (favicon + карточка)
icons.extraApp     — путь к PNG-иконке дополнительного приложения

Блок: URL-адреса версий
------------------------
urls.mainManifest    — URL глобального манифеста основного приложения
urls.mainVersionBase — базовый URL папки с версиями основного (до «v{версия}/»)
urls.extraManifest   — URL манифеста дополнительного приложения
urls.extraVersionBase — базовый URL папки с файлами Extra

Из этих значений app.js автоматически формирует ссылки на установщики:
  основное:       {mainVersionBase}v{v}/PostalApp_Setup_v{v}.exe
  дополнительное: {extraVersionBase}PostalApp-Extra_Setup_v{v}.exe

Блок: firebase
--------------
Стандартный объект конфигурации Firebase (apiKey, authDomain, projectId и т.д.).
Используется в initFirebase() для инициализации firebase.initializeApp().
Если apiKey пустой или начинается с «ВАШ» — показывается toast-ошибка и
функциональность Firebase отключается.

Блок: контакты
--------------
contact.email    — email (отображается в футере)
contact.telegram — ссылка на Telegram. Если пустая строка — кнопка скрывается.

Блок: heroSubtitle
-------------------
Текст подзаголовка в hero-секции. Вставляется в innerHTML элемента #hero-subtitle.

Блок: waveGrid
--------------
Управляет анимированной волновой сеткой (Canvas) в hero-секции.
  enabled     — включить/выключить (false = canvas не рисуется)
  cellSize    — размер ячейки в px
  lineColor   — CSS-цвет линий (rgba или hex)
  lineWidth   — толщина линий
  opacity     — прозрачность всего canvas-слоя

  hAmplitude / hFrequency / hSpeed — параметры горизонтальных волн
  vAmplitude / vFrequency / vSpeed — параметры вертикальных волн
  Speed = 0 означает статичную сетку без анимации.

Блок: tickerSpeed
-----------------
  row1 — длительность одного цикла первой строки бегущей строки (секунды)
  row2 — то же для второй строки (движется в обратном направлении)
  Больше значение = медленнее движение.

Блок: lightboxPanLimit
-----------------------
Максимальное смещение изображения в пикселях при перетаскивании в лайтбоксе
при zoom = 1. При большем зуме граница пропорционально увеличивается (limit × zoom).

Блок: screenshots
-----------------
Массив объектов {src, caption}.
  src     — путь к изображению
  caption — подпись под скриншотом в карусели и лайтбоксе
Если массив пуст — секция скриншотов скрывается (display:none).
Порядок массива определяет порядок слайдов.
