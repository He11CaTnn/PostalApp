Возможности

Всё для управления доставкой

Четыре уровня доступа, карта маршрутов, управление подписками — в одном приложении для Windows.

🗺️

Карта и маршруты

Построение оптимальных маршрутов на основе алгоритма 2-opt. Отображение участков доставки, адресов и почтовых отделений.

👥

Ролевой доступ

Четыре роли: Почтальон, Оператор, Руководитель подписок и Директор. Каждый видит только то, что нужно для работы.

📰

Управление подписками

Регистрация читателей, оформление и продление подписок, импорт данных из Excel с валидацией.

🔄

Автообновления

Встроенная система обновлений с проверкой MD5, поддержкой критических обновлений и откатом на предыдущую версию.

🔒

Безопасность

Шифрование конфигурации через SSL Pinning, хеширование паролей PBKDF2 и проверка целостности файлов.

📋

Постановка задач

Директор создаёт и назначает задачи почтальонам с привязкой к конкретным адресам на карте. Контроль выполнения в режиме реального времени.
